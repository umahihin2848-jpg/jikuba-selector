# 1着レンジ × 1軸 vs 2軸包囲 過去検証

## 目的
枠連3〜14位を対象に、1着レンジを軸候補フィルターとして使った場合、1軸と2軸のどちらが効率的かを比較する。

## 固定ルール
- 対象：既存393レース（2022=96 / 2023=100 / 2024=99 / 2025=98）
- 1着レンジ：v2.20 の boundary score ロジックを最終単勝オッズへ適用
- 主分析：1着レンジ end<=6 の「狭いレンジ」だけ
- 軸スコア：市場推定2着内率 × 枠内代表度
- 1軸：軸スコア最高の1頭
- 2軸：軸スコア上位2頭。可能なら別枠
- 枠連：実際の枠連人気3〜14位決着のみ捕捉対象
- 相手削減：単勝50倍未満 / 100倍未満を比較
- 2022–23を開発側、2024–25をホールドアウト側として比較
- すべて最終オッズ。T-15ではない

## 393レース：ホールドアウト2024–25
### 相手100倍未満
|方式|対象N|軸が2着内|枠連3〜14決着|最終馬連捕捉|3〜14決着時の変換成功|
|---|---:|---:|---:|---:|---:|
|1軸|103|50/103 = 48.5%|48/103 = 46.6%|19/103 = 18.4%|19/48 = 39.6%|
|2軸|103|73/103 = 70.9%|48/103 = 46.6%|31/103 = 30.1%|31/48 = 64.6%|

2軸は1軸より +12/103 = +11.7pt の最終捕捉。1軸で当たり2軸で外れたケースは0、1軸で外れ2軸で当たったケースは12。対応あり比較のMcNemar exact p≈0.00049。

95% Wilson CI：
- 1軸 最終捕捉 18.4% [12.1%, 27.0%]
- 2軸 最終捕捉 30.1% [22.1%, 39.5%]
- 2軸 軸2着内 70.9% [61.5%, 78.8%]

50→100倍へ広げても2024–25では2軸で1的中しか増えない（30→31）。

## 1着レンジは効いているか
2024–25・2軸・相手100倍未満：

|1着レンジ|N|軸2着内|枠連3〜14|最終捕捉|
|---|---:|---:|---:|---:|
|狭い end<=6|103|70.9%|46.6%|30.1%|
|広い end>=7|94|52.1%|59.6%|28.7%|

狭い1着レンジは軸2着内率を +18.8pt 改善（two-proportion p≈0.0068）。
しかし枠連3〜14決着率は逆に -13.0pt。最終捕捉率は30.1% vs 28.7%でほぼ同じ（p≈0.83）。

解釈：1着レンジは「レースを買う/見送るゲート」より、「軸の信頼度を高める軸生成フィルター」として使う方が合理的。

## 結論
1. 2軸化そのものには強い捕捉改善がある。
2. ただし2軸は点数増加が大きく、合成オッズが2倍台前半まで落ちやすい。
3. 1着レンジend<=6は軸生存率を有意に高めるが、同時に3〜14決着率を下げるため、ハードなレース除外には向かない。
4. したがって現時点の本命構造は：
   - 1着レンジ → 軸候補生成
   - 1軸/2軸は合成オッズで切替
   - 枠連3〜14位
   - 相手50倍未満を基本、50〜100倍は拡張帯
5. 次の検証は「2軸を常時使う」のではなく、1軸→2軸へ増やした時の追加捕捉 / 追加点数 / 合成オッズ低下をレース単位で判定するルール。

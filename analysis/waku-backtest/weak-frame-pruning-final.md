# 2軸BC包囲：弱い相手枠削減・最終検証メモ

## 検証設計
- 対象：2022〜2025年 393/393R
- 2022〜23：開発側 196R
- 2024〜25：ホールドアウト側 197R
- 主分析：現行1着レンジ end<=6 のレース
- 2軸：1着レンジ内から市場推定2着内率×枠内代表度で選定
- 枠連：3〜14人気
- 相手馬：単勝50倍未満を基本
- 使用オッズ：確定単勝・確定枠連・確定馬連
- T-15オッズではない

## 相手枠の予測可能性
相手枠モデルのAUC：
- 2022〜23：0.676
- 2024〜25：0.645

予測スコア四分位の実際の相手枠捕捉率：
- 下位25%：2022〜23 1.7% / 2024〜25 1.6%
- 25〜50%：5.2% / 4.7%
- 50〜75%：6.0% / 7.9%
- 上位25%：12.0% / 8.6%

弱い相手枠を事前オッズだけである程度識別できる。

## 解釈しやすい弱枠ルール
候補相手枠について、次のどちらかに該当：
1. 枠連人気11〜14位
2. 相手枠の単勝市場支持率5%未満

この「弱枠候補」の相手枠捕捉率：
- 2022〜23：4/149 = 2.7%（Wilson 95%CI 約1.0〜6.7%）
- 2024〜25：3/168 = 1.8%（Wilson 95%CI 約0.6〜5.1%）

それ以外の相手枠は概ね7〜8%程度で、弱枠候補より高い。

## 2軸・全相手枠 vs 弱枠削除（2024〜25）
|指標|全相手枠|弱枠削除|
|---|---:|---:|
|対象R|103|103|
|最終馬連捕捉|32/103 = 31.1%|29/103 = 28.2%|
|元の的中を保持|100%|29/32 = 90.6%|
|平均点数|11.22点|8.60点|
|平均合成オッズ|2.42倍|3.11倍|
|均等買いROI|75.4%|83.5%|
|ダッチROI|72.1%|74.8%|

効果：
- 点数 約23.4%削減
- 合成オッズ 約28.8%上昇
- 元の的中の約90.6%を保持
- ROIは改善したが100%には届かない

年別：
- 2024：平均合成3.37倍、均等ROI85.5%
- 2025：平均合成2.89倍、均等ROI82.0%
圧縮効果は両年で確認できた。

## 合成3.5〜4倍まで強制的に削る案
2024〜25：
|方式|的中率|元的中保持|平均点数|平均合成|均等ROI|
|---|---:|---:|---:|---:|---:|
|全相手枠|31.1%|100%|11.22|2.42倍|75.4%|
|3.5倍以上まで削る|18.4%|59.4%|7.26|4.19倍|75.1%|
|4.0倍以上まで削る|15.5%|50.0%|6.53|4.78倍|75.0%|

結論：合成3.5〜4倍を作るために相手枠を追加削除する方式は、的中を失いすぎてROIも改善しない。採用しない。

## より保守的なモデル削減
モデル下位20%相当を削る探索では2024〜25で：
- 32/32的中を維持
- 平均点数 11.22→10.22
- 平均合成 2.42→2.63
- 均等ROI 75.4→82.8%

ただし「20%」はホールドアウト確認後の探索値なので、正式ルールとしては未採用。

## 現時点の推奨仕様
1. 1着レンジ → 2軸候補生成
2. 2軸から枠連3〜14位を包囲
3. 相手馬は単勝50倍未満を基本
4. 枠連11〜14位 または 相手枠支持率5%未満を「弱枠候補」と表示
5. 弱枠候補だけ削除した後の合成オッズを表示
6. 合成3.5〜4倍に届かないからといって、さらに相手を切らない
7. 合成オッズは買い判断の情報として表示し、現段階では自動購入判定にしない

## 統計的結論
「弱い相手枠を削って合成オッズを押し上げる」という考えは成立している。
ただしそれは現時点では **利益を生む主シグナルではなく、買い目圧縮機能**。
次に必要なのは、圧縮前の2軸BC戦略そのものを「買うレース／見送るレース」に分けて、ベースROIを上げるレース選別モデルの検証。

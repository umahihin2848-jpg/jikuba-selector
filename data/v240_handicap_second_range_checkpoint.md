# v2.40 ハンデ戦・2着レンジ再検証チェックポイント

対象: JRA平地 OP/L のハンデ戦。2023〜2024年。現行v2.40相当の高信頼条件（1着レンジ5〜8、1着境界成立、Neff比0.85〜0.95を除外）を、最終単勝オッズから再計算。

## 全体
- N=39
- 1着捕捉: 36/39 = 92.3%
- 現行2着レンジ捕捉: 32/39 = 82.1%
- 1・2着同時捕捉: 30/39 = 76.9%

年別:
- 2023: N=20 / 1着20/20 / 2着16/20 / 同時16/20
- 2024: N=19 / 1着16/19 / 2着16/19 / 同時14/19

## 固定安全幅を置いた場合
実際の2着人気を固定上限で捕捉する場合:
- 1〜8人気: 2着32/39 = 82.1% / 同時30/39 = 76.9%
- 1〜9人気: 2着34/39 = 87.2% / 同時32/39 = 82.1%
- 1〜10人気: 2着34/39 = 87.2% / 同時32/39 = 82.1%
- 1〜11人気: 2着36/39 = 92.3% / 同時33/39 = 84.6%
- 1〜12人気: 2着38/39 = 97.4% / 同時35/39 = 89.7%

## 暫定評価
- ハンデ高信頼型は1着側92.3%で単勝候補としては維持可能。
- 2着側は現行レンジ全体では82.1%、同時76.9%で、馬連を自動昇格させる根拠として不足。
- 「2着レンジ1〜10型」は2023 4/4・2024 4/4・合計8/8だがN=8のため正式化しない。
- 「2着レンジ1〜8型」は全体10/11=90.9%だが2024単年4/5=80%で時系列安定性が不足。
- 狭い2着レンジ（5〜7）が必ずしも安全ではなく、むしろ2着人気が外へ飛ぶ例がある。
- 当面はハンデ戦＝単勝中心。馬連は2着構造の追加条件をさらに検証してから昇格。

# V5 A14 前向き検証プロトコル

## 1. 基準版
- 運用版: V5 A14 / 1.0
- 凍結ブランチ: `release/v5-a14-1.0`
- 凍結コミット: `09986b41c32530ab1d9c1882efb81dff4e642082`
- 専用iPhone smoke: Chromium / WebKit とも成功
- 前向き検証開始: 2026-10-10以降の、解析時点で結果が未確定のJRA平地レース

## 2. 目的
V5 A14が、開発時に見ていない将来レースでも再現するかを確認する。

評価を次の3層に分け、混同しない。
1. 確率・順位モデルの予測性能
2. 市場構造・人気レンジ・シナリオ等の補助構造指標
3. 実際に購入した馬券のROI

## 3. 凍結ルール
前向き検証期間中は、結果を見て予測ロジックを変更しない。

許可:
- バグ修正
- 表示崩れ修正
- 文言・配色・レイアウト改善
- 保存/復元等の非予測機能修正

原則禁止:
- M3の特徴量・係数・順位ロジック変更
- calibrated probability の再学習・閾値変更
- RPCI/シナリオ計算の重み変更
- 市場構造の閾値変更
- 構造浮上の定義変更
- 人気レンジのTop3定義変更

予測ロジックを変更する場合は別バージョンとして扱い、A14の前向き成績とは混ぜない。

## 4. レース前に必ず固定する項目
結果確定前に保存する。

### レース情報
- 日付
- 競馬場
- R
- レース名
- 格
- 芝/ダート
- 距離
- 頭数
- 馬場
- オッズ取得時刻（原則T-15）

### A14出力
- 市場構造ラベル
- 市場構造値（G1〜G3等のSTRUCTURE SCORE、OPはOOS実測値として別管理）
- 中心人気帯（基礎確率Top3の実人気）
- 人気レンジ最遠人気
- 基礎確率Top3の実人気位置
- M3 Top3の実人気位置
- 主シナリオTop3の実人気位置
- 主シナリオ（HIGH / MIDDLE / SLOW）と表示確率
- M3 Top3の馬番
- 構造浮上馬
- 各馬のwin/top2/top3基礎確率（保存できる場合）
- probability monotonicity audit
- M3 parity audit

## 5. レース後に追記する項目
- 1〜3着馬番
- 1〜3着最終人気
- 構造浮上馬の着順
- 基礎確率Top3から勝ち馬を捕捉したか
- 基礎確率Top3から3着内馬を何頭捕捉したか
- M3 Top3から勝ち馬を捕捉したか
- M3 Top3から3着内馬を何頭捕捉したか
- 主シナリオTop3から勝ち馬を捕捉したか
- 主シナリオTop3から3着内馬を何頭捕捉したか
- 人気レンジ最遠人気以内に勝ち馬が入ったか
- 人気レンジ最遠人気以内に3着内3頭が入ったか

## 6. 馬券ROIを検証する場合
予測性能と馬券ROIは別集計にする。

集計対象にできるのは、発走前に以下を固定した購入だけ。
- 買う/買わない
- 券種
- 買い目
- 1点金額
- 総投資額
- 使用した判断理由

レース後に買い目を作ったもの、結果を見て除外したものはROI集計に入れない。

記録項目:
- 投資額
- 払戻額
- 利益
- ROI
- 的中/不的中
- 最大ドローダウン
- 最大連敗
- 年/月/格/芝ダート/距離帯別の件数

## 7. 集計タイミング
小標本でロジックを動かさないため、毎レースの結果は記録するがモデル評価は頻繁に変更しない。

- 速報確認: 50レース到達時
- 第1正式評価: 100レース到達時
- 以後: 100レース単位、またはシーズン終了時

重要なバグがない限り、50レース未満の上下だけで予測ロジックを変更しない。

## 8. 正式に見る指標
### 確率モデル
- Log Loss
- Brier Score
- ECE
- AUC（補助）
- 予測確率帯ごとの実測率

### 順位/構造モデル
- Top1 winner capture
- Top3 winner capture
- Top3 overlap
- M3と基礎確率の乖離別成績
- 構造浮上馬の3着内率
- 人気帯別成績
- 主シナリオ別成績

### 人気レンジ
- 勝ち馬捕捉率
- 3着内3頭すべての捕捉率
- 最遠人気別の成績
- 基礎/M3/主展開の各レンジ別成績

### ROI
- Bet count
- Hit rate
- Average odds
- Stake
- Return
- ROI
- Profit
- Max drawdown
- Max losing streak
- Bootstrap confidence interval（十分な件数がある場合）

## 9. OP市場構造の扱い
OPの表示は個別レースの予測確率ではなく、固定した頭数帯のOOS実測頻度。

- 10頭以下
- 11〜15頭
- 16頭以上

開発時OOSを既に確認済みのため、2026-10-10以降は新しい前向き確認セットとして扱う。
G1〜G3等のSTRUCTURE SCOREと同一指標として混ぜない。

## 10. 変更管理
A14から予測ロジックを変更する場合、必ず以下を残す。
- 変更日
- 変更理由
- 変更前後のコード/モデル
- A14前向きデータを新モデルの調整に使用したか
- 新しい検証開始日

A14の前向き成績は、その後のモデル成績と合算しない。

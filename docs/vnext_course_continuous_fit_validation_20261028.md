# vNext Course × Continuous Position Fit Validation — 2026-10-28

現行Productionコードは未変更。

## 目的

Position Loss v3で補正した予測位置を、4区分ではなく連続値のままコース適性へ接続できるかを確認する。

対象は、2019–23の年抜き検証で位置効果が安定し、2024–26にも十分な確認件数があった7コースのみ。

- 東京芝1600 C
- 阪神ダ1800
- 東京芝2400 B
- 中京芝1200 A
- 中山芝1800 A
- 中山芝2500 A
- 東京芝2400 C

2019–23を開発、2024–26を確認。2024–26を見て個別コースの最適番手や閾値は探索しない。

---

## 1. 自由な個別コース曲線は棄却

最初に、各コースについて位置の一次・二次項を持つL2正則化モデルを試した。

2019–23内LOYOでは一見改善したが、2024–26では悪化。

2024–26 313頭:

| model | AUC | LogLoss | Brier |
|---|---:|---:|---:|
| base | 0.8113 | 0.3769 | 0.1188 |
| base + course label | 0.8112 | 0.3769 | 0.1188 |
| base + course-specific raw curve | 0.7989 | 0.3885 | 0.1217 |
| base + course-specific v3 curve | 0.7910 | 0.3949 | 0.1248 |

### 判定

**🗑 棄却**

コースごとに自由な連続曲線を学習させるのはサンプルに対して高次元で、過学習した。

---

## 2. 低次元の連続適性へ変更

以前2019–23だけで固定した各コースの「好位置4区分」を再利用し、その区分中心だけを固定する。

中心:

- 前25% → 0.125
- 25–50% → 0.375
- 50–75% → 0.625
- 後25% → 0.875

今回の予測位置を0=前、1=後ろの連続値とし、

`CourseFit = -abs(predicted_position - development_preferred_center)`

とする。

この1変数のみを既存ベースモデルへ追加。個別コース別の新しい係数・閾値は作らない。

---

## 3. 2024–26確認結果

| model | AUC | LogLoss | Brier |
|---|---:|---:|---:|
| base | 0.8113 | 0.3769 | 0.1188 |
| + raw position continuous fit | 0.8157 | 0.3737 | 0.1175 |
| + v3 position continuous fit | 0.8150 | 0.3725 | 0.1169 |

v3-fit vs baseのレース単位bootstrap:

- AUC改善 mean +0.0040, 95%CI -0.0141〜+0.0213, 改善確率 約68%
- LogLoss改善 mean +0.0044, 95%CI -0.0085〜+0.0163, 改善確率 約77%
- Brier改善 mean +0.0019, 95%CI -0.0018〜+0.0056, 改善確率 約85%

CIは0を跨ぐため「確定した独立改善」とは扱わない。

raw-fit vs v3-fitでは、v3がLogLoss/Brierでやや良いがCIは0を跨ぐ。したがって **Position Loss v3がCourse Fitを明確に改善したとはまだ言えない**。

## 5. 判定

### Course continuous fit

**🧪 → 採用候補**

条件:

- 2019–23内で再現性確認済みのコースのみ
- 1変数の連続距離として使う
- 個別コースごとに自由な曲線を学習しない
- Axisへの強い昇降格はまだしない

### Position Loss v3との統合

v3はQueue精度改善としては✅採用済み。

ただしCourse Fitに接続した際の追加改善はまだ小さいため、

**v3補正位置を表示上の正本とするが、Course Fitの統計的根拠は「好位置中心への連続距離」そのものに置く。**

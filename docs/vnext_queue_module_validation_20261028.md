# vNext Queue Module Validation — 2026-10-28

基準: `vnext-logic-ledger` / 現行Productionコードは未変更。

## 目的

Position Loss v3、P10-v3、Front Pack Separation (FPS) を、同じWalk-forward母集団・同じ2024–26確認集合で再整理し、役割の重複とAxisへの接続可否を固定する。

- 開発: 2019–23
- 確認: 2024–26
- 対象: G1–G3 / 12頭以上のうちPosition Loss v3に必要な隊列データが揃った516レース・8,186頭
- 2024–26確認集合: 2,904頭
- 2024–26を見て新しい閾値探索は行わない

---

## 1. Position Loss v3

目的は「元の隊列予測から、実際にはどれだけ後ろへズレるか」を予測すること。

2024–26:

- MAE: 0.2017 → 0.1928
- RMSE: 0.2458 → 0.2407
- Race bootstrap MAE改善: +0.0088, 95%CI +0.0073〜+0.0102
- Race bootstrap RMSE改善: +0.0052, 95%CI +0.0035〜+0.0067
- 2019〜2026の全8年でMAE/RMSE改善方向

一方、Ability/M3/市場/元のQueue等を含むフルOutcomeモデルへ直接追加した2024–26増分はほぼ0。

### 判定

**✅ 採用**

ただし役割は **隊列補正**。Axis Reliabilityへ独立加点しない。

---

## 2. P10-v3

目的は「今回、最初の有効通過順位が10番手以下になる確率」。

同じ形式の校正モデルで、旧隊列ベースとv3補正隊列を比較。

2024–26:

| model | AUC | LogLoss | Brier |
|---|---:|---:|---:|
| P10 base proxy | 0.7927 | 0.5374 | 0.1798 |
| **P10-v3** | **0.8034** | **0.5258** | **0.1755** |

固定運用帯でもP10-v3は単調性を維持。

- <20%: 実際の後方化 約12.5%
- 20–50%: 約35%
- 50–65%: 約53%
- >=65%: 約76.5%

ただしフルOutcomeモデルには既に`pred_front`が含まれており、そこへP10-v3を追加しても増分はほぼ0。

SpearmanではP10-v3と`pred_front`が約 -0.95、Position Loss v3とは約 +0.71。

### 判定

**✅ 採用**

役割は **隊列情報を人間に理解しやすい後方化確率へ圧縮する表示/リスク指標**。

P10-v3をAxisへ別点として加えるとQueue情報の二重計上になりやすいため、ハードゲート・独立加点は禁止。

## 3. Front Pack Separation (FPS)

`FPS = 予測先行スコア1位 - 6位`。

- 小さい: 前方集団が圧縮
- 大きい: 前方が分離 / 縦長

FPSはP10-v3とのSpearman相関が全馬で約 -0.03で、位置取り確率とはかなり独立。

全2,904頭へ一律にOutcome特徴として追加しても増分はほぼ0だった。

一方、事前固定HIGH CORE

- history >= 3
- 1番人気
- Ability rank <= 3
- M3 rank <= 4

に限定し、2019–23で固定したFPS四分位境界を2024–26へ適用すると:

| FPS | 2019–23 Top3 | 2024–26 Top3 |
|---|---:|---:|
| Q1 最も圧縮 | 53.3% | 50.0% (7/14) |
| Q2 | 55.2% | 50.0% (11/22) |
| Q3 | 58.6% | 66.7% (10/15) |
| Q4 最も分離 | 72.4% | 93.3% (14/15) |

2024–26 Q4−Q1差 = +43.3pt。
単純bootstrap 95%CIは約 +14.8〜+71.4pt、正方向確率約99.9%。ただし確認側のHIGH COREは66頭だけで、Q4は15頭なので絶対率93.3%をそのまま将来値とはみなさない。

### 判定

**🧪 強い候補**

FPSを「全馬の好走点」として一律加算しない。

使うなら **軸候補が既に強いレースで、その軸信頼度を補助するレース構造指標** とする。

S昇格材料候補だが、2027 Forwardでの確認前にProductionへ強加点しない。

## 4. 3モジュールの役割分担

```text
Validated Queue
   ↓
Position Loss v3
   └─ 今回の予測位置を補正
   ↓
P10-v3
   └─ 10番手以下になる確率として表示

レース全体では別枝:
Front Pack Separation
   └─ 前方集団の圧縮/分離を示す
```

### Axisへの接続

- Position Loss v3: Axisへの独立加点なし
- P10-v3: Axisへの独立加点なし / ハードゲート禁止
- FPS: 強い軸候補に対する独立確認候補。まだShadow

つまり、Position Loss v3とP10-v3は **Queue内部の精度・説明性向上**、FPSは **Race-level uncertainty/confidence** として分ける。

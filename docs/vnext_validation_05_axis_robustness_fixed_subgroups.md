# vNext Validation 05 — Axis A/B/C/D robustness by fixed race conditions

更新日: 2026-10-28

## 目的

vNext Axis A/B/C/Dが、全体集計だけでなく事前固定した主要条件でも崩れないか確認する。

Axis境界は Validation 04 で固定済み。今回、条件別に閾値を再最適化しない。

対象は各レースのAxisBase最上位1頭。

- 2019–23: 556レース（LOYO OOF score）
- 2024–26: 310レース（既知確認期間）

固定条件:

- Grade: G1 / G2 / G3
- Surface: 芝 / ダート
- Distance: ～1599m / 1600–1999m / 2000m以上
- Field: 12–15頭 / 16–18頭

評価:

1. A/B/C/Dの3着内率
2. A−D差
3. TierをD=0,C=1,B=2,A=3としたlogistic trend
4. Tier効果が条件により変わるか interaction LRT

## 主要結果

### Grade

2019–23:

- G1: A 78.2% / B 67.6% / C 50.0% / D 20.0%（D n=5）
- G2: A 71.4% / B 55.3% / C 52.8% / D 40.7%
- G3: A 54.3% / B 51.6% / C 55.6% / D 36.4%

2024–26:

- G1: A 71.4% / B 56.2% / C 50.0% / D 50.0%（D n=2）
- G2: A 82.4% / B 80.0% / C 50.0% / D 42.9%
- G3: A 73.3% / B 56.7% / C 55.8% / D 28.4%

G3 developmentではB/Cが逆転するが、A>D方向は維持。G1のDは確認期間n=2のため条件性能を判断しない。

### Surface

2019–23:

- 芝: A 72.4% / B 56.8% / C 55.5% / D 38.0%
- ダート: A 56.5% / B 57.1% / C 45.0% / D 20.0%

2024–26:

- 芝: A 72.7% / B 64.9% / C 50.6% / D 31.7%
- ダート: A 88.9% / B 64.3% / C 77.8% / D 37.5%（A n=9, C n=9）

芝は安定。ダートは小標本でB/Cが揺れるが、A−D差は両期間でプラス。

### Distance

2019–23:

- ～1599m: A 76.2% / B 55.9% / C 53.3% / D 46.7%
- 1600–1999m: A 67.3% / B 51.7% / C 56.1% / D 29.5%
- 2000m以上: A 69.7% / B 63.8% / C 51.9% / D 39.6%

2024–26:

- ～1599m: A 66.7% / B 63.6% / C 65.2% / D 17.4%（A n=9）
- 1600–1999m: A 88.9% / B 57.6% / C 46.2% / D 40.5%
- 2000m以上: A 69.2% / B 74.1% / C 52.9% / D 32.0%

2000m以上の確認期間ではB>Aだが差は小さく、A−Dは+37.2pt。短距離はA/B/Cが近く、Dだけ大きく低い。

### Field size

2019–23:

- 12–15頭: A 72.9% / B 54.3% / C 62.7% / D 34.2%
- 16–18頭: A 67.5% / B 58.1% / C 48.9% / D 37.6%

2024–26:

- 12–15頭: A 77.8% / B 65.6% / C 65.5% / D 34.5%
- 16–18頭: A 73.1% / B 64.1% / C 47.8% / D 31.1%

両頭数帯でA>Dが安定。12–15頭ではB/Cの分離が弱い。

## Trend test

2024–26のTier ordinal logistic trend:

- G2 OR/tier 2.05, p=0.003
- G3 OR/tier 1.88, p<0.001
- 芝 OR/tier 1.83, p<0.001
- ～1599m OR/tier 2.16, p=0.006
- 1600–1999m OR/tier 1.81, p=0.001
- 2000m以上 OR/tier 1.77, p=0.003
- 12–15頭 OR/tier 1.78, p=0.002
- 16–18頭 OR/tier 1.87, p<0.001

G1とダートは小標本のためtrend pは有意でない。

## Interaction test

Tier効果が条件によって統計的に変化するかを、main effect model vs tier×condition modelのlikelihood-ratio testで確認。

2019–23:

- Grade p=0.183
- Surface p=0.977
- Distance p=0.899
- Field p=0.871

2024–26:

- Grade p=0.715
- Surface p=0.940
- Distance p=0.828
- Field p=0.842

いずれも有意なinteractionは確認されなかった。

これは「G1用Axis」「短距離用Axis」など条件別に別モデル/別境界を作る根拠が今のところないことを支持する。

## 結論

- ✅ A/B/C/Dの大枠は固定条件でも維持する。
- ✅ 条件別にAxis閾値を変更しない。
- ✅ AとDの分離は主要条件で概ね安定。
- ⚠ B/Cは条件によって入れ替わりやすく、近い信頼帯として扱う。
- ⚠ G1-D、ダートA/C、短距離Aなど小標本セルを理由に条件補正を作らない。
- 🗑 「G1では別閾値」「16頭以上はAを格下げ」等の後付けルールは作らない。

次の必須検証は、Queue完全予測が揃わないレースに対するFallback設計。

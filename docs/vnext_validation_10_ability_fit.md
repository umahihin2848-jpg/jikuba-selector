# vNext Validation 10 — 能力適性

更新日: 2026-10-28

## 目的

5能力（速力 / 超速力 / 加速力 / 持続力 / 消耗戦）を、Axisへの追加点ではなく、馬のタイプ説明・相手候補の特徴付けとして使えるか再整理する。

## 既存検証の統合結果

### 1. 5能力そのものの再現性

2019–2026で各能力の次走再現性は毎年正方向。
全期間Spearman:

- 速力: 0.367
- 超速力: 0.440
- 加速力: 0.327
- 持続力: 0.346
- 消耗戦: 0.316

超速力が最も安定。

### 2. 5能力は相関が高い

代表相関:

- 速力×持続力: 0.793
- 速力×加速力: 0.725
- 超速力×加速力: 0.761

PCAではPC1だけで61.7%を説明。
5能力を独立加点すると二重計上になりやすい。

### 3. レース要求能力

レース側の要求プロフィール予測はSpeed/Ultraで再現性が高い。
一方Sustainは2024–25/2026でR2がほぼ0まで低下するため、5能力すべてを同じ信頼度で扱わない。

### 4. Ability Match

馬の5能力プロフィールとレース要求の一致度はraw集計では強い勾配を再現。

2024–25 Top3率:
- Q1: 7.6%
- Q2: 12.9%
- Q3: 19.2%
- Q4: 35.6%

2026:
- Q1: 12.4%
- Q2: 15.7%
- Q3: 19.6%
- Q4: 28.9%

しかしAbility/M3等を含むbase modelへ追加した増分はほぼ0。
BootstrapでもAUC/LogLoss/BrierのCIが0を跨ぐ。
2026では微悪化。

解釈: Ability Matchは「強い馬を再発見」する要素が大きく、Axisへ別加点すると二重計上。

### 5. Queue × Ability Type

圧縮/分離などとの記述差はあるが、interaction係数は年代で符号が安定しない。
全Universeでもinteraction追加の増分は実質0。

### 6. Pace vulnerability

HIGH COREで脆弱群は一貫して低め:
- 2019–23: 54.8% vs 66.9%
- 2024–26: 50.0% vs 66.2%

ただし小標本かつ増分CIは0跨ぎ。
VetoやAxis減点にはしない。

## vNext採否

- 5能力プロフィール: 👁 Display
- レース要求プロフィール: 👁/🧪 Display + Shadow
- Ability Match: 👁 Display。Axis加点禁止
- Queue×Ability interaction: 🧪説明研究。Axis加点禁止
- Pace vulnerability: 🧪軽い警告表示。Veto禁止
- 5能力の単純合算: 🗑

## UI方針

能力適性は「点数」ではなく、以下を並列表示する。

- この馬の強み: 超速力 / 加速 / 持続 / 消耗戦など
- 今回レースが要求しそうな能力
- 一致度: 高 / 中 / 低（説明用）
- Pace vulnerability: あり / なし / 不明

この表示はAxis A/B/C/Dを書き換えない。

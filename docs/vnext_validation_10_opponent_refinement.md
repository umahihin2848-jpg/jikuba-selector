# vNext Validation 10 — 相手馬診断の細分化

更新日: 2026-10-28

## 目的

相手候補を「市場上位4頭 + 1頭救済」だけで扱うと、候補内の優先順位が雑になる。
そこで、相手候補を分かりやすい日本語で4段階に整理し、開発期と確認期で再現するかを見る。

対象は、軸馬が成立したレース。
- ワイド相手評価: 軸が3着内
- 馬連相手評価: 軸が2着内
- 2020–23: 開発側
- 2024–26: 確認側

## 1. 市場上位4頭の中を3段階に分ける

市場上位4頭について、Ability上位4位以内とM3上位4位以内の一致数で分類する。

- 本線相手: 市場上位4 + Ability上位4 + M3上位4
- 有力相手: 市場上位4 + Ability/M3のどちらか一方が上位4
- 押さえ: 市場上位4だがAbility/M3はいずれも上位4外

### ワイド側: 相手馬自身の3着内率

|期間|本線相手|有力相手|押さえ|
|---|---:|---:|---:|
|2020–23|41.9%|31.3%|26.9%|
|2024–26|41.4%|28.5%|23.3%|

2024–26のrace-bootstrapでは、本線相手 - 押さえ = +18.4pt、95%CI 約 +5.3〜+31.2pt。
本線相手は押さえより明確に上。

### 馬連側: 相手馬自身の2着内率

|期間|本線相手|有力相手|押さえ|
|---|---:|---:|---:|
|2020–23|21.7%|12.1%|15.9%|
|2024–26|30.8%|18.8%|8.6%|

確認期では本線 > 有力 > 押さえが明確。
開発期は有力/押さえが逆転するため、有力と押さえを強く分離しすぎない。

## 2. 旧「構造救済1頭」の再確認

旧qScoreは市場順位とのSpearman相関が約 -0.90、単勝オッズとも約 -0.94。
そのため「市場外から構造で拾う穴馬」という名称は正確ではない。
実態は市場5〜6番手付近の有力馬をもう1頭足す性格が強い。

今後は名称を「人気次点」に変更する。

### 市場上位4 + 人気次点

相手を1頭以上拾える率:
- ワイド: 2020–23 89.0% → 94.5%、2024–26 85.7% → 90.1%
- 馬連: 2020–23 61.7% → 72.3%、2024–26 66.2% → 76.1%

この5頭目はProduction候補として維持する。

## 3. 本当の「穴候補」を別に検証

市場上位4頭外から、Ability順位 + M3順位の合計が最も小さい馬を「穴注目」として試した。
これは市場順位を直接使わない。

相手1頭以上捕捉率:
- ワイド 2024–26: 市場上位4 85.7% → 穴注目追加 93.4%
- 馬連 2024–26: 市場上位4 66.2% → 穴注目追加 74.6%

ただし2020–23では、既存の「人気次点」の方がやや安定。
さらに、人気次点を入れた後に穴注目を6頭目として追加した独自増分は:
- ワイド 2020–23: +0.0pt
- ワイド 2024–26: +3.3pt
- 馬連 2020–23: +0.0pt
- 馬連 2024–26: +1.4pt

確認期では少し上乗せがあるが、開発期ではゼロ。
したがって穴注目を自動買い目候補6頭目へ昇格させない。
Shadow表示のみ。

## 4. vNextの相手馬表示

専門用語は使わず、画面では次の4分類にする。

1. 本線相手
   - 人気・Ability・M3が全部一致
   - 最優先

2. 有力相手
   - 人気に加え、AbilityまたはM3が一致
   - 次点

3. 押さえ
   - 人気上位だがAbility/M3の裏付けは弱い
   - 市場評価を尊重して残すが優先度は下

4. 穴注目
   - 市場上位4外でAbility/M3が良い
   - Shadow表示のみ
   - 自動追加しない

別枠で「人気次点」を5頭目候補として表示する。
これは旧qScore救済の正しい解釈。

## Production方針

- 相手候補は最大5頭を基本とする
- 市場上位4頭は候補の土台
- 5頭目は「人気次点」
- 上位4頭の中は 本線相手 / 有力相手 / 押さえ に分ける
- 穴注目は6頭目として買い目へ自動追加しない
- 2027 Forwardで穴注目の独自増分を継続確認
- Pair probability上位2頭だけへの自動絞り込みは禁止

## 注意

この分類は相手馬の優先順位を説明するためのもの。
馬券を自動生成するものではない。

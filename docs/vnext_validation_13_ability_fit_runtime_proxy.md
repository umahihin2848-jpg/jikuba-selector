# vNext Validation 13 — 能力相性の実装用Proxy

## 目的
既存の5能力（速力 / 超速力 / 加速力 / 持続力 / 消耗戦）の検証結果を、TARGET CSVからWebアプリ上で再現し、相手馬カードへ「今回向き / 標準 / 今回は少し合いにくい」として表示する。

この層は **説明専用**。Axis A/B/C/D、相手の本線/有力/押さえ順位、BUY/PASS、買い目点数を変更しない。

## 表示用の言葉
- 速力 → 全体の速さ
- 超速力 → 一気に速い脚を使う力
- 加速力 → ギアを上げる鋭さ
- 持続力 → 長く脚を使う力（参考）
- 消耗戦 → 苦しい流れで踏ん張る力

持続力のレース要求予測は他4項目より確認が弱いため、画面上でも「参考」と明記する。

## 開発固定
### 馬側
2019–2023のみで、TARGET互換の発走前履歴データから各過去走の5能力を近似する Ridge を固定。直近最大5走、3走以上で相性判定。

2024–25の元5能力との順位相関：
- 全体の速さ: 0.907
- 一気に速い脚: 0.920
- ギアを上げる鋭さ: 0.890
- 長く脚を使う力: 0.715
- 苦しい流れで踏ん張る力: 0.663

2026も同方向：0.906 / 0.910 / 0.889 / 0.705 / 0.636。

### レース側
競馬場・距離・頭数・芝/ダ・馬場・格・月だけから、今回求められそうな5能力の重みを予測するモデルを2019–2023で固定。

研究時のQueue値はブラウザ実装と完全同一ではないため、RuntimeではQueueを要求能力モデルへ混ぜない。

## 相性
馬の5能力をレース内順位（percentile）へ変換し、固定式

`sum(((percentile / 50) - 1) * predicted_weight)`

で相性を計算する。

区切りは2019–2023で固定：
- score < -0.2480778297 → 今回は少し合いにくい
- -0.2480778297 以上 0.5761231013 未満 → 標準
- 0.5761231013 以上 → 今回向き

2024–25の3着内率（利用可能データ）:
- 少し合いにくい: 6.95%
- 標準: 17.92%
- 今回向き: 38.54%

2026:
- 少し合いにくい: 14.44%
- 標準: 15.29%
- 今回向き: 36.02%

ただしこの差の多くは既存Ability/M3と重なるため、予測確率への追加加点には使わない。

## Runtime再現性
検証済みPythonモデルをraw-spaceの小型係数へ変換。
- 過去走5能力: 最大数値差 約 5.7e-14
- レース要求能力: 最大数値差 約 2.2e-16

初回の手動係数転記に不一致を検出したため、その版は使用せず、検証済みモデルから機械変換した係数へ置換した。

## UI
相手カードの本線/有力/押さえ判定は従来どおり維持し、その下へ補助説明を追加する。

例：
- 今回の相性：今回向き
- 強み：一気に速い脚を使う力・ギアを上げる鋭さ
- 一気に速い脚を使う力が今回の条件に合いやすい

履歴が3走未満なら「材料少なめ」とし、無理に相性を出さない。

## 禁止
- 能力相性をAxisへ加点しない
- A/B/C/Dを変更しない
- 「今回向き」だけで相手順位を上げない
- 「今回向き」だけで買い目へ自動追加しない
- 2024–26を見て区切りを再調整しない

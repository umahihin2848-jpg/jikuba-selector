    買えるレース数・4段階バランス

    保存済みの直近100レースを現在のv2.40ロジックで再判定し、強候補 / 条件付き / 見送り推奨 / 固定ロックの比率を表示します。ロジックが厳しすぎないかを見る指標です。

    保存時4段階の前向き成績

    v2.40-balance-2以降に保存した分類は後から動かさず、その時点の「強候補 / 条件付き / 見送り推奨」ごとに実成績を比較します。

    固定ロック監査

    過去保存データに固定ロック該当条件が残っている場合だけ、結果を監査します。ロック解除・維持の判断材料で、現在の購入禁止は自動解除しません。

    単勝・馬連・ワイド 実戦成績

    単勝・馬連・ワイドを別会計で集計。券種ごとの的中率・回収率を独立して確認できます。
    詳細な検証DBを見る

    v2.39 型別・前向き検証

    保存時点の「条件×オッズ構造」型キーごとに、1着・2着・同時捕捉と実購入成績を集計します。結果を見て型キーや閾値を後から動かさず、v2.39以降の記録だけで再現性を確認します。

    v2.20以降・境界スコア検証

    v2.19以前は除外。固定人気レンジではなく、そのレースごとの最有力境界を使った判定だけを検証します。

    1着・2着レンジ検証DB

    実際の1着が1着レンジ内、実際の2着が2着レンジ内だったかを別々に検証します。3着以下は使いません。

    判定履歴

    レース戦略 v2.41。基本は単勝、馬連は追加条件通過時のみ。ワイドは同じ軸・相手候補から追加し、別会計で前向き検証します。

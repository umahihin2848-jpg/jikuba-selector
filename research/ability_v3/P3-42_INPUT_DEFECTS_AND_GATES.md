# P3-42｜M3入力の3件の確定不具合と修正・検証（2026-11-17）

研究用Draft PR #5のみ。本番 `main` は変更していない。M3/M4係数・AxisAccessGate・購入／見送り判定は変更していない。

## 1. 重複過去走を直近5走と誤認

`umadete.csv` 439,416行中、馬名＋レースIDで74,724レコードだけが一意。同一過去走の繰返しが364,692行。障害・中止等を除いたあとの重複は350,909行（以前のデータ監査）。
`target-csv-compat-v1.js` は今回馬番を初出馬名順で保ちつつ、歴史的16文字レースID＋馬名が同一の行を重複除去する。レースIDがないデータは危険な日付推定では潰さない。比較対象フィールドが異なる場合には`historyConflictCount`が増える。

2024中山金杯17頭、保存済み残600m位置を固定した代理再計算では重複有無でM3順位15/17頭が変わり、予測追い上げ値の平均絶対差は0.203秒。**保存済み順位への再現は2/17頭にとどまる。** 

## 2. 別のCSVが同じキャッシュを返す

**原因：** `File.name|size|lastModified|type` を内容同一性の判定に使用。異なるFileオブジェクトでもメタデータが一致すれば旧変換バッファを流用する。

**再現：** 同じメタデータで内容だけが違うCSVのC馬・D馬を順に読んだところ、修正前はD馬を要求してもC馬を取得。GitHub Actions `44068977630` の失敗ログ。

**対処：** ファイル本体の同一性でだけ再利用する `WeakMap<File, Promise<ArrayBuffer>>` とし、メタデータ横断キャッシュを除去。`clear()` もそのWeakMapを新規化。修正後の `44069101015` は成功。

## 3. 過去レースの集計で未来走を参照

**原因：** `finish600-simulator-v2.js` 自身の `hist()` は事前日付フィルターをかけるが、上流の `ShapeCore.summarize` は過去5**行**を選ぶだけで、今回レース日を知らなかった。そのため保存履歴がレース日以降まで含まれるCSVで上流のRPCIや上3F地点差に未来情報が入り、残600m推定も汚染され得る。

**再現：** 2026-04-01のレースを指定し、2026-06-07／当日／不正日付／それ以前2走を入力。旧ロジックは5行採用、修正後は発走日前の2走のみ。`44069574446` で旧ロジックの失敗を観測。

**対処：** `C.analyze` からレース日を `C.summarize` に渡し、入力日が指定された場合は `0 < 履歴日付 < レース日` の行だけで特徴量を計算。存在しない日付とレース当日も除外。研究CI `44069677898` は成功。

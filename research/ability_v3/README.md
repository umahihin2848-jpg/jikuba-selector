# Ability C × V3 本番アプリの分析機能（2026-11-17）

公開ページ: `https://umahihin2848-jpg.github.io/jikuba-selector/waku-bc-converter/v3.html`

既存の「単勝オッズ」欄の下に「Ability C × V3 研究モード」を追加しています。**これは本番Webサイトで使える分析用パネルです**が、未検証の研究予測をそのまま馬券の購入許可に変換するものではありません。既存の軸(C × M3, A1/A2, 上位6番人気からの再選定)、相手Top2、見送りロックには一切書き込まず、独立した読み取り専用表示です。

## できること

- 能力C、V3（Dynamic+Peak, 730日）、M3順位、単勝市場を同一表に表示
- 本番構造軸と研究用「市場＋C」「市場＋V3」軸を比較
- 研究用の相手4頭を「市場＋C」「C軸＋C/V3混合」で比較
- 市場構造が良好でもC×M3で軸が未確定なら、**購入ロックを解除せず**「再点検対象」として表示
- 発走前予測をSHA-256付きJSONとして保存し、レース後の1〜3着を別JSONで照合（端末時刻・利用者入力であり第三者時刻証明ではありません）

## 使い方

1. 通常どおりレース条件、対象出走馬全頭のTARGET過去走CSV、全頭の単勝オッズを入力して「レース構造を解析」。
2. 単勝オッズ欄の下の「Ability C × V3 研究モード」を展開する。
3. 過去271レースは出走表が一致すればV3特徴量が自動的に照合されます。**新しいレースはV3特徴量CSVを事前生成して取り込む必要**があります。V3特徴量は現在のアプリに入力した直近5走だけからは再計算できません。
4. 番付・軸比較・相手比較・見送り再点検を確認する。どの研究値も現行アプリの購入判定を変更しません。
5. 発走前予測の固定・結果照合では、公式発走予定時刻と利用者の確認が必要です。HTTPS環境でJSONをダウンロードし、レース後に保存済みJSONを再読込します。

## 新規レースのV3特徴量の生成

Python環境（`pip install numpy pandas`）と**2016年以降のJRA全馬成績CSV**、当日の確定出走表CSVが必要です。今回出走馬だけの履歴は不可です。TARGET成績CSVはCP932。出走表はUTF-8で、必要列 `date,venue,surface,distance,no,name,age`（任意で`rid`）を12〜18頭分記録します。

```sh
python research/ability_v3/export_v3_pre_race.py \
  --history 2026_2025_seiseki.csv 2026seiseki.csv \
  --card upcoming_card.csv --out upcoming_v3.csv
```

生成された `upcoming_v3.csv` を本番画面の研究パネルに取り込みます。開催日、競馬場、芝ダ、距離、全頭の馬番と馬名が一致しない場合は適用されません。2026年研究モデルは2025年までで学習済み。2027年以降は年次再学習なしに外挿しません。

## 予測の継続検証

発走前JSONとレース後JSONを同一フォルダに保存後、PCで実行します。

```sh
node research/ability_v3/aggregate_forward_receipts.cjs --dir ./receipts --out ./reports
```

`forward_race_audit.csv`, `forward_summary.csv`, `rejected_files.csv`が出力されます。結果は利用者入力。現行では払い戻し・ROI・実馬券の期待値を算出しません。

## 安全上・精度上の注意

- 市場構造の0.60は「単勝1番人気の3着内予測確率」の研究値で、軸＋相手4頭の同時好走率・回収率・購入許可ではありません。
- 2024〜2026年の271レースは研究で繰り返し使った検証済み期間。将来成績の保証にはなりません。
- CとV3の3着内推定確率は完全に較正されていません。
- 本番のC × M3軸・相手Top2・見送りロックの挙動は維持。ユーザーの購入操作・外部サービスへの送信はしません。
- ブラウザの実機iPhone Safariでの全体E2Eは未検証。WebCryptoはHTTPSを使用してください。

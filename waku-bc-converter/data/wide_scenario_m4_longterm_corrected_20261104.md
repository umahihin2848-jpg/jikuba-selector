# ワイド展開シナリオ別M3・長期検証：オッズ照合修正版

**研究専用 / 現行Productionは変更しない / 2026-11-04**

## 再現上の重要事項
2016〜2026履歴から、2019〜2026の未知年でAbility / M3 / RPCIシナリオ予測 / シナリオ別M4を前年までのデータで年次再学習。対象は12〜18頭、JRA平地3勝クラス以上。ただし過去の全クラスデータや本人の手動シナリオは完全に再現できないため**アプリ本番の忠実な過去実行ではなく代理バックテスト**。

TARGETのオッズレースキーで、開催日10=A、11=Bなどの**16進文字**を見落とすと異なるレースを紐づける重大バグがあるため修正。全戦略6,358件のレース頭数、馬番、ワイド両側対称性、保存オッズ一致を監査し**不一致0件**。旧集計は使わない。

## 判断
今回の代理検証で、シナリオ別M3＋Ability＋人気帯に**長期収益の再現性は確認できなかった**。市場は最終確定ワイドの下限/上限（T-15実行価格や正確な払戻額ではない）。本人の決め打ちシナリオの履歴がないため本人の実購入手法の収益性を否定しない。

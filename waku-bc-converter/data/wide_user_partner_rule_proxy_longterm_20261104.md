# ワイド購入パターンの長期探索的検証（2026-11-04）

## ステータス
**RESEARCH ONLY / NOT AN EXACT REPLAY / NOT FOR PRODUCTION**

ユーザーの実際の買い方：アプリ軸1〜4人気なら相手5人気以下を優先し、価格が合わなければ相手1〜4人気へ。軸が5人気以下なら相手は1〜4人気。5人気以下×5人気以下は原則避ける。着順の再現性を重視。

## 今回の再構築用の暫定ルール
- JRA平地12頭以上、3勝クラス以上。
- 2019〜2026年ウォークフォワード。Ability/M3を各年より前の歴史で再学習した**代理モデル**。元のアプリと同一ではない。履歴は `umade.csv` に入っている上位クラスのみで、本物のM3/P10には必要な全過去走を完全再現しない。
- 軸候補はAbility Top3とM3 Top3の一致が厳密に1頭、Ability順位1位または2位、単勝人気1〜6位のものだけ。
- 過去最大5走の上位クラス着順の正規化順位平均から標準偏差の半分を差し引いた数値で相手馬の「再現性」を近似。
- 軸が1〜4人気なら5人気以下・ワイド下限オッズ5倍以上の相手から再現性最上位1頭。該当なしで相手1〜4人気に戻す設計だが、本試験では**一度もフォールバックしなかった**。つまり「オッズの釣り合い」を十分に再現できていない。
- 軸5〜6人気なら相手1〜4人気から再現性最上位1頭。
- 同じレース1点、均等1u。オッズは確定表示のワイド下限・上限で払い戻し近似。購入時価格でも確定払戻金でもない。

## 重要な解釈
この結果が示すのは「**人気帯と単純な過去着順安定度だけで機械的に買えば長期で勝つ、という仮説は支持されなかった**」ということに限られる。ユーザーが実際に見ている同条件・同脚質・ペース・不利・レース内容、オッズの相対的な釣り合い、見送り判断は未再現。現行Productionの軸と完全一致していないため、本人の戦略の反証としない。

# 枠連BCコンバーター 収束・資金曲線検証 v1

## 目的
期待値がプラスであっても、実戦では分散により長期間マイナスになり得る。そこで、実購入結果から「何購入で黒字確率がどの程度まで高まるか」「最大ドローダウンがどれくらいになり得るか」を推定する。

## 使用データ
アプリに保存された実購入履歴のみを使う。

各購入について

- 実投資額 stake_i
- 実払戻額 return_i

から、1単位購入の総回収倍率を

g_i = return_i / stake_i

と定義する。

これにより、購入額が日ごとに違っても、まず手法そのものの収益分布を等額購入として評価できる。

## 実績指標

- 実回収率 = Σreturn / Σstake
- 等額換算ROI = mean(g_i)
- 的中率 = P(g_i > 0)
- 最大1件寄与率 = max(return_i) / Σreturn_i

最大1件寄与率が高い場合は、高配当依存による収束遅延を警告する。

## ブートストラップ
観測済みの g_i を復元抽出し、将来N購入の列を作る。

各シミュレーションで

ROI_N = (Σ g_i*) / N

を計算する。

さらに累積純損益

C_t = Σ_(k=1..t) (g_k* - 1)

を作り、過去最高値との差から最大ドローダウンを計算する。

## 表示する購入数

- N=50
- N=100
- N=300
- N=500
- N=1000

各Nで以下を表示する。

1. 黒字確率 P(ROI_N > 1)
2. ROI中央値
3. ROIの5〜95%範囲
4. 最大ドローダウンの95パーセンタイル（stake units）
5. 指定した1レース想定購入額を掛けた円換算DD

## 必要nの補助概算

1購入あたり純収益を

x_i = g_i - 1

とする。

標本平均を μ、標本標準偏差を σ とすると、独立同分布・正規近似のもとで累計黒字確率が目標qを超える購入数は

N_q ≈ (z_q σ / μ)^2

で概算する（μ>0の場合のみ）。

表示対象:

- 80%: z=0.841621
- 90%: z=1.281552
- 95%: z=1.644854

これは右裾の長い競馬収益には近似が粗いため、ブートストラップを主、正規近似を補助とする。

## サンプルサイズの扱い

- n < 30: 判断材料にしない
- 30 ≤ n < 100: 探索的
- 100 ≤ n < 300: 実用目安が見え始める
- 300 ≤ n < 1000: 収束速度推定にかなり使える
- n ≥ 1000: 強い母数。ただし年度別・条件別の安定性確認は継続

1000という数字は「本番で1000購入しないと期待値が発生しない」という意味ではない。期待値は1購入目から存在するが、実収支が理論値へ近づく確率が購入数とともに高まる。

## 本稼働ゲート
本番ロジックの完成判定は、次の両方を要求する。

### A. 期待値ゲート
- アウト・オブ・サンプルで市場ベースラインを上回る
- p校正が大きく崩れない
- 歪み帯と実測優位性に再現性がある

### B. 運用可能性ゲート
- 100/300/500/1000購入の黒字確率を確認
- 95%最大ドローダウンが許容資金内
- 特定の1〜2高配当への依存が強すぎない
- 想定年間購入数から現実的な期間で検証・運用できる

## 実装
`risk-validation.html` が同一オリジンの localStorage `wakuBcTranslatorV2` を読み、現在の実購入結果から上記を自動計算する。

注意: ブートストラップは未観測の超高配当や将来の市場構造変化を表現できない。従って結果は「現在の観測分布が続く場合の条件付き推定」であり、保証ではない。

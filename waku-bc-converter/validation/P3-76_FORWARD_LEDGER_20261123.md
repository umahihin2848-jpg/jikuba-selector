# P3-76｜発走前台帳と自己申告購入の結果照合（2026-11-23）

## 目的
P3-74の予想JSONを、レース開始前に購入判断・購入金額・見送り理由と一緒に保存し、P3-75の成績CSVとHR2払戻で「仮想100円比較」と「本人申告の購入成績」を分けて照合する。購入見送りも漏れなく台帳の1レースとして保存する。

## 対象
- 既存の `rsa-p374-buy-skip-research-snapshot-v1` をそのまま予想原本とする。
- 本画面は研究専用・完全ローカル動作。本番 Ability / M3 / P10 / 買い目 / 購入判定 / BUY/PASS を変更しない。
- 新規スキーマ `rsa-p376-forward-declaration-v1` に予想全体・SHA-256・レースキー・保存した端末時刻・本人申告の購入／見送り・購入明細（馬連/ワイド、組番、投資額、購入日時、参考照会番号）を保存する。
- 予想原本のJSON文字列の `JSON.stringify` をSHA-256で照合。原本は照合後も変更しない。
- 端末時刻、購入日時、ハッシュと自己申告は発走前・実購入の第三者検証ではない。購入照会画面、レシートなどは別途保持する。未来レースでの運用記録が中心。

## 使用手順
1. 発走前にv3 P3-74で「見送りを含めJSON保存」してP3-76に読み込ませる。
2. 確定した競馬場・日付・レース番号と、実際の購入／見送りを登録する。購入したときは組番・券種・支払額・購入日時を入力。見送りでも台帳を保存。1レースごとにJSONを端末へ保存する。
3. レース終了後、P3-76に台帳JSONを複数読込し、TARGET結果CSVとJRA-VAN HR2払戻TXTを読込して集計する。
4. 仮想比較はP3-75の `P10最小 / レース質 / P3-74判断尊重` をワイド・馬連別に、1レース100円予算で検証。本人申告実購入は**実入力の金額・券種・点数**で別集計。見送りは投資0円のまま残す。
5. 照合結果のJSONには原本台帳・検証したハッシュ一致結果・購入・見送り・保留・仮想100円比較を全て残す。

## 欠落・二重計上防止
- R番号・確定出走表が必要で、レース日より後の自己申告台帳を発走前として扱わない。
- 確定出走表が未確認なら購入申告は不可。
- 同一レースの複数台帳は全件保留。予想内容やSHA-256が食い違う場合、比較成績には算入しない。
- P3-75の厳格なレース・馬番・全頭氏名・グレード・払戻の整合チェックを再利用。
- 未照合レースは未購入とみなさず、保留として別表示。
- 発走前予想が保存されていないレースは遡及して予想を補わない。既探索年度に対する後付け予想は未知年検証から除外。
- 購入実績が100円固定とは限らないため、実購入成績と仮想100円回収率を「同額条件での勝ち負け」と解釈しない。

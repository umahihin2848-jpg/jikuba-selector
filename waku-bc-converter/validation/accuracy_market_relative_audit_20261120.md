# 予測精度：市場と独立した軸・相手選択＋同オッズ帯の比較（2026-11-20）

## 目的
「市場1番人気より3着内率が低い」という比較だけでは、より高配当の非1番人気の軸候補を正しく評価できない。市場オッズは**検証時の比較情報**として扱い、予測する軸馬・相手3頭の選定はAbility C/v1・M3の構造評価に固定する。

## 変更した実装
- `mobile-focused-3tabs-v1.js`：画面に表示する軸候補をAbility×M3の構造軸から独立抽出。過去の購入条件・人気範囲による表示抑止を廃止し、市場オッズ入力では軸・相手3頭のメンバーを変更しない。
- 同モジュールの `partnerReference`：Ability順位優先、M3順位をタイブレーク参考。C＋市場の参考3着内推定が取得できた場合、**候補順位に反映せず参考数値としてのみ表示**。モデル本体の順位を更新しない。
- `prediction-accuracy-notebook-v1.js`：発走前保存時に現在フォームと実際に解析したレース条件（日付・場・レース名・芝ダ・距離・頭数・クラス・馬場）を照合。不一致なら保存せず再解析を要求。確認済みCSV番号・時刻・解析完了状態のチェックは維持。
- `prediction-benchmark-audit-v1.js`：発走前の全馬人気・単勝オッズが揃う場合、非1番人気軸の3着内率、人気帯・オッズ帯の成績、同レース・同オッズ帯対照の成績を集計。オッズ欠損は比較対象外とし、欠損件数を表示。
- `v3.html`：新モジュール読込・キャッシュ識別子を更新。
- **購入条件のBUY/PASSや本番のAbility/M3学習係数は変更しない。** モバイルの3タブは分析用の表示のみとする。

## 事前に固定した市場対照ルール（今回の新規予測から適用）
- 同一レースにおいて選択軸の発走前単勝オッズの **2/3〜1.5倍** の馬を対照候補にする。軸自身は除外。
- 対照馬が2頭以上揃ったレースのみ、軸の3着内結果（1/0）と対照馬の3着内率の差を**レース単位で等重み**集計。対照馬が1頭以下なら比較不能として別計上。
- 「非1番人気」は発走前の入力人気2位以下で定義する。未入力時に非1番人気と推測しない。
- 人気別：1人気／2〜3人気／4〜6人気／7人気以下。オッズ別：5倍未満／5〜9.9倍／10〜19.9倍／20倍以上。
- 単純な軸好走率にはWilson 95%区間、30レース以上の平均差にはレース単位の分散に基づく参考近似区間を表示。これらは選択バイアス・複数探索・モデル開発への既存データ利用を補正するものではない。CIがプラスでも必ずしも未知レースで優位とは限らない。
- **現在の収集データは発走前のスナップショット**。レース後の最終オッズを遡及入力しない。市場人気・オッズが不完全なレースを勝手に補完しない。

## 品質保証
- `prediction-benchmark-audit-v1.test.cjs`：同オッズ帯2頭以上、非1番人気、オッズ無し、1頭のみ、単勝1.0倍、重複等の5ケース。
- `mobile-focused-market-independence.test.cjs`：市場条件外でも軸表示維持、オッズ入力前後で相手候補が同じ2ケース。
- 既存の予測精度・外れ方11件と合わせて**計18件の保存可能な回帰テスト**。
- 模擬画面で「オッズなしの発走前記録」「レース名を変えた後の記録拒否」「市場比較の表示」を確認。
- GitHub Pages実配信とiPhone Safari実機でのCSV→予測→公式結果入力は未確認。

## 残る制約
- 真の発走前記録の信頼性は端末時計と利用者の時刻・馬番照合確認に依存し、独立したサーバー時刻の保証はない。
- 小標本では僅かな的中の有無で値が大きく変わる。人気帯・オッズ帯は集計表示するが、**自動的に閾値を最適化する機能には使わない**。
- 2025〜2026年Ability C再構成と元研究の29R／32R不一致は継続課題。今回の検証結果は過去モデル性能を再保証しない。

# 枠連BCコンバーター 歪みモデル正式仕様 v1

## 目的
単勝・枠連・馬連の3市場を同一の確率スケールへ正規化し、単勝から予測される枠連/馬連構造に対して、実際の枠連市場が与える追加情報が馬連市場に十分反映されていない組み合わせを「市場間歪み」として測る。

重要: 歪み値はそれ自体を真の的中確率や購入根拠とはみなさない。アウト・オブ・サンプルで追加予測力が確認されるまでは診断指標としてのみ扱う。

## 入力
発走前の同一時点（本番はT-15を固定）で以下を取得する。

- 全馬の単勝オッズ
- 成立する全枠連オッズ
- 成立する全馬連オッズ
- 各馬の枠番号
- レース結果（検証時のみ）
- レース格（G1/G2/G3/L/OP/3勝）

市場時点は必ず統一し、後から直前オッズへ差し替えない。

## 1. 市場確率の正規化

単勝:

p_i = (1 / O^win_i) / Σ_k(1 / O^win_k)

枠連:

F_ab = (1 / O^frame_ab) / Σ_(u,v)(1 / O^frame_uv)

馬連:

Q_ij = (1 / O^quinella_ij) / Σ_(r,s)(1 / O^quinella_rs)

これにより券種ごとの控除・オーバーラウンドの影響を可能な範囲で除き、3市場を確率スケールで比較する。

## 2. 単勝から馬連の基準確率を作る

Harville / Plackett-Luce型の順序モデルを基準モデルとして使用する。

P(i→j) = p_i × p_j / (1 - p_i)

馬連は順不同なので、

H_ij = p_i × p_j / (1 - p_i) + p_j × p_i / (1 - p_j)

H_ijは「単勝市場だけを知っている場合に期待される馬連構造」の基準値であり、真の確率とは断定しない。

## 3. 単勝から理論枠連確率を作る

枠aと枠bに属する全馬連ペアのH_ijを合計する。

H^frame_ab = Σ H_ij  (i∈a, j∈b)

同枠枠連では同一馬を除き、組み合わせを一度だけ数える。

## 4. 枠内での馬連シェア

w_ij = H_ij / H^frame_ab

これは「枠連a-bが成立した条件下で、単勝市場から見て馬連i-jが占めるべき相対シェア」。

## 5. 枠連市場を反映した期待馬連確率

E_ij = F_ab × w_ij

## 6. 正式な歪み倍率

D_exact_ij = E_ij / Q_ij

対数歪みスコア:

S_ij = log(D_exact_ij)

解釈:

- D_exact = 1: 枠連市場と馬連市場が整合
- D_exact > 1: 枠連市場の評価に対して馬連側が相対的に薄い
- D_exact < 1: 枠連市場の評価に対して馬連側が相対的に厚い

重要: D_exact=1.5を「真の確率が50%高い」とは解釈しない。市場間不一致の強さを示す診断値である。

## 7. 公開最終オッズを使うパイロット近似

全馬連の正規化定数を取得できない公開データでの一次検証では、

D_raw_ij = (O^quinella_ij / O^frame_ab) × w_ij

を近似指標として使う。

D_rawはD_exactとは異なる。T-15本番検証ではJRA-VAN等から全市場を同時点で取得してD_exactを使う。

## 8. 統計モデル

まず市場の馬連確率Q_ijを基準とし、歪みが結果に追加情報を持つかを推定する。

logit / conditional-logit等で、少なくとも以下を比較する。

Baseline: 馬連市場Qのみ

Distortion model: 馬連市場Q + S_ij

必要に応じて、

log(weight_ij) = log(Q_ij) + β_class × S_ij

として、βを格別に学習する。

当初は少なくとも次の2層を分離する。

- OP以上: G1/G2/G3/L/OP
- 3勝クラス

3勝クラスへOP以上のβを流用しない。

## 9. 検証設計

時系列を守る。

推奨:
- 2021-2024: 学習
- 2025: 校正/仕様固定
- 2026: 完全アウト・オブ・サンプル最終評価

評価指標:
1. 対数尤度 / log lossの改善（Baseline Qのみ vs Q+S）
2. β_class > 0 が時系列で安定するか
3. 歪み帯が高くなるほど実測/市場期待比が概ね単調増加するか
4. Brier score / calibrationの悪化がないか
5. 実際の購入ルール適用後のROI、最大ドローダウン、購入数

単一のp値だけで採用しない。

## 10. 実装ゲート

現時点ではD_exact/Sを「購入判定」「EV補正」に直接使用しない。

本番ロジックへ昇格する条件:
- 完全な同時点オッズでD_exactを計算できる
- 格別モデルで十分な母数を確保する
- アウト・オブ・サンプルでQのみのベースラインを一貫して上回る
- 歪み帯と実測優位性に方向性/単調性が確認できる
- ROIだけでなく確率校正も改善または少なくとも悪化しない

ゲート通過前はUIに「実験指標」としてのみ表示・保存可能。

## 11. 2025公開最終オッズ パイロット結果

`distortion-pilot-2025.csv` に個票を保存。

18レース時点:

- 全体: 12/18でD_raw>1、幾何平均1.063、平均logD +0.061
- OP以上: 10/11でD_raw>1、幾何平均1.156、平均logD +0.145
- 3勝: 2/7でD_raw>1、幾何平均0.932、平均logD -0.071

OP以上は仮説と同方向、3勝は現時点では同方向ではない。ただし手作業で選んだ小標本・最終オッズ・D_raw近似であるため、これを有意な優位性の確定とはみなさない。

## 12. 現時点の実装方針

- 現行の市場3段p / 合成オッズ / EVロジックは変更しない
- 歪みモデルを既存EVへ混ぜない
- 次段階ではD_exact/Sを診断値として保存できるようにする
- OP以上と3勝は別集計・別係数
- T-15完全データで検証ゲート通過後のみEV補正候補へ昇格

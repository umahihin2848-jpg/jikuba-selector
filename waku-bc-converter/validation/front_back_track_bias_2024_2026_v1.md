# 前後トラックバイアス検証 v1

作成日: 2026-10-16

## 目的

同一開催・同一日のそれまでのレースから「前有利 / 後ろ有利」を推定し、後続レースのM3/Abilityとは独立した前後バイアス表示に使えるかを検証する。

今回の主眼は、単純な逃げ・先行残りではなく、**能力・市場・ペースを差し引いた前後の上振れ/下振れが同日後続レースへ持続するか**である。

## 使用データ

- `umade.csv`: 3勝クラス以上の馬別結果、2016-2026
- `2026_2025_seiseki.csv`: 2016-2025の3勝クラス以上の結果・単勝オッズ
- `2026seiseki.csv`: 2026の3勝クラス以上の結果・単勝オッズ
- 感度分析: `umadete.csv` のうち、出走頭数に対する収録馬数が95%以上の完全に近いレース

障害は除外。前後位置は1角から順に最初に取得できる通過順位を頭数で0-1正規化した `frontness` を使用した。

## 設計

### 1. 通常の前後効果を除く

2016-2020を基準期間として、3着内を目的変数に以下を使ったロジスティック回帰を固定した。

- log(単勝オッズ)
- 頭数
- 距離
- 芝/ダート
- 競馬場
- クラス
- 実測RPCI
- 実測frontness
- RPCI × frontness

各馬について `実績3着内 - 予測3着内確率` を残差とし、各レース内でその残差とfrontnessの傾きを「そのレースの前後バイアス観測値」とした。

これにより、単なるスロー前残りや能力上位馬の先行勝ちをそのまま前有利と数えないようにした。

### 2. 後続レースへの持続性

同一日・同一競馬場・同一芝ダートについて、対象レースより前のレースだけを使用。未来レースは使用しない。

前走までの同日バイアス平均を縮小して後続レースの説明変数とし、2021-2023でモデル係数を学習、2024で縮小強度を選択、2025/2026で確認した。

比較は、過去3走の前後位置傾向 `hist_front3` を含む基準モデルに対して、

- 同日バイアス
- 同日バイアス × 過去位置取り傾向

を追加したときのBrier / AUC / log loss。

なお2025/2026は本プロジェクトで既に繰り返し参照しているため、pristine OOSではなく**回顧的holdout / sensitivity**として扱う。

## データ上の重要な制約

アップロード済みの全成績データは主に3勝クラス以上であり、1Rから12Rまでの全レース全頭結果ではない。

そのため同日・同場・同芝ダートで「前のレース」が1つ以上存在した割合は、

- 2024: 20.7%
- 2025: 19.2%
- 2026: 19.4%

2レース以上存在した割合は、

- 2024: 1.8%
- 2025: 1.0%
- 2026: 1.8%

に留まった。

したがって今回の検証は、**1つ前の高クラスレースだけで当日バイアスを読む方法が使えるか**には答えられるが、午前から3-6レースを積み上げる本来の当日バイアス推定を十分には検証できない。

## 結果1: 2024 development

同日バイアスの縮小係数 `n/(n+k)` の k を 0, 0.5, 1, 2, 4, 8, 16 で比較した。

全候補で基準モデルよりBrierは改善せず、最も悪化が小さかったのが k=16。

- k=16: ΔBrier = +0.0000089
- ΔAUC = -0.0000668
- Δlog loss = +0.0000907

つまりdevelopment時点でも、強く縮小しないとノイズが増えた。

## 結果2: 固定k=16の年別確認

### 2025

- 基準Brier: 0.1391414
- +前後Bias: 0.1391526
- 差: **+0.0000112（悪化）**
- AUC: 0.780036 -> 0.779936

### 2026

- 基準Brier: 0.1363478
- +前後Bias: 0.1364098
- 差: **+0.0000620（悪化）**
- AUC: 0.786621 -> 0.786527

改善は再現しなかった。

## 結果3: 2025-26 race/day-cluster bootstrap

Brier差 = `+Bias - 基準`。負なら改善。

### 全対象馬

- 平均差: +0.0000329
- 95% CI: **[-0.0000263, +0.0001005]**

### 同日以前レースが1つ以上ある馬のみ

- 平均差: +0.0001357
- 95% CI: **[-0.0001757, +0.0004736]**

統計的にも実用的にも改善は確認できない。

## 結果4: レース単位の前後バイアス持続性

3着内だけではノイズが大きいため、着順を0-1化した連続パフォーマンスでも別検証した。

同一日・同一場・同一芝ダートの「直前レースBias」と「次レースBias」の相関:

- 2024: r = +0.050
- 2025: r = +0.027
- 2026: r = +0.002
- 2025-26 pooled: **r = +0.017**

2025-26 pooled回帰:

- 傾き: +0.016
- SE: 0.069
- p = 0.814

**直前1レースの前後Biasが次レースへ持続する証拠はなかった。**

## 結果5: `umadete.csv` 完全レース感度分析

出走頭数の95%以上が揃ったレースだけを使い、2023で通常効果を固定して2024-26を確認した。

2025-26 pooled:

- 直前レースBiasとの相関: r = +0.045
- 回帰傾き: +0.044
- SE: 0.071
- p = 0.541

同じ結論。

## 結果6: 前開催日からの持ち越し

同競馬場・同芝ダートで前開催日との間隔が2日以内のday-level Biasを比較。

2025-26 pooled:

- r = +0.0004
- 回帰傾き = +0.0004
- p = 0.995

前日のBiasをそのまま翌日のpriorにする根拠も得られなかった。

## 結論

### 現時点でやってはいけないこと

- 直前1レースだけで「今日は前有利」と表示する
- 前日Biasを翌日に持ち越す
- いまの結果からM3順位やTop3確率を補正する

これらは現在データでは支持されない。

### 重要な解釈

「前後バイアスが存在しない」とは結論できない。

今回のデータでは、午前からの全レースを順番に蓄積できず、約80%の対象レースで同芝ダートの事前Bias観測が0件、2件以上は約1-2%しかない。

したがって、今回否定されたのは主に

> **直前1レース程度の高クラス結果から当日Biasを読む方法**

である。

本来検証したい

> **同日1Rからの全レースを3-6本蓄積し、能力・ペース補正後に縮小推定した前後Bias**

は、まだ十分なデータがない。

## 次の正しい検証

TARGETから最低でも2023-2026のJRA平地全レース・全頭を出力する。

必要列:

- 日付
- 場所
- R
- 芝/ダート
- 距離
- 馬場状態
- クラス
- 頭数
- 馬番
- 馬名または血統登録番号
- 確定着順
- 単勝オッズまたは人気
- 通過1-4
- PCI
- レースPCI/RPCI（可能なら）

このデータで、各後続レース時点に1Rからの同芝ダート過去レースだけを逐次利用し、

1. 通常の前後効果を学習
2. 各レースの能力・ペース補正済みBiasを算出
3. 1レース後 / 2レース後 / 3レース後 / 4レース後以上で信頼度を比較
4. Empirical Bayes / Kalman型の縮小をdevelopment年で固定
5. 翌年でBrier・log loss・M3残差・Top3を確認
6. 何レース目から実用化可能かを決める

という手順が必要。

## Production decision

**前後TRACK BIASは現時点では未実装。**

全カードデータで再検証するまでは研究項目として保留する。

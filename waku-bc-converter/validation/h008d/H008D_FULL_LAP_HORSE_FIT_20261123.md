# H008-D｜全ラップ × 馬の経験ラップ適性 × M3（2026-11-23）

**判定：全ラップ照合と馬別研究指数の作成までは完了。市場＋M3研究再構成への独立な上積みは確認できず、正式モデルへの自動加点は HOLD。**

## 1. 今回新しく検証した問い

前のH008-A/Cは「コース側のレースラップ」を87条件で測った。本研究では、*各馬が実際に経験した過去の各200mラップ*を当時の結果（人気に対する着順）と結合し、今回のコースで発生しやすいフルラップ形状との適合を発走前に求め、Ability/M3へ拡張可能な指標になるか確認した。

先に結論を書くと、**コースがレース全体に要求する負荷**は相当数のデータで復元可能だが、**馬固有の能力**はレース全体ラップだけでは十分分離できていない。過去に「速いラップのレースを走った」ことと「自分自身がその速さを発揮した」ことは異なる。

## 3. 全ラップの分解（コース要求側）

計測するもの：①最初のスタート区間、②序盤の負荷、③道中の巡航・緩急、④後半4Fの水準とピーク、⑤急加速、⑥高速持続、⑦最後200mの減速。全200m区間の相対形状（8点）も保持する。

過去に紹介された「速力・超速力・加速力・持続力・消耗戦」という理論に対応する**レース要求の代理量**を次のように設計（馬固有の実測アビリティではない）。

| 代理量 | 元ラップからの計測 | 注意 |
|---|---|---|
| 速力要求 | 最後4Fの平均1F時計（速いほど高要求） | 芝/ダ・距離・馬場と分けて比較 |
| 超速力要求 | 最後4Fで最速の1F時計（10秒台/11秒前半等） | 馬自身が同じ最速脚を使った証拠ではない |
| 加速力要求 | 最後3F付近で、加速後が11.8秒未満になる最大のラップ短縮幅 | 単に13秒→12秒へ緩やかに戻るケースを過大評価しない |
| 持続力要求 | 最後4Fのラップばらつき（小さいほど均等） | 遅い4Fでも均等になり得るため、速力と必ず併読 |
| 消耗戦要求 | 終盤3F平均−スタート後序盤2F平均＋最後1Fの減速量 | 前半負荷と最後の失速を別々に保持 |

## 4. 馬別LapFit研究指数の定義

1. 発走前に判明する競馬場×芝ダ×距離×コーナー数から、**発走前に存在した過去レースだけ**で期待ラップ8点＋初区間＋5要求量を計算（同条件12レース以上、少ない場合は過去の同芝ダ・距離・コーナー数に縮小）。
2. 馬の過去最大15異レースのラップ形状と今回要求形状の近さを計算。距離差・芝ダ違い・コーナー数違い、走歴の古さで減衰させる。
3. 過去の人気から期待される相対着順との差（当時の成績残差）を、近いラップ条件と単なる近い距離・馬場条件の間で比べる。
4. 根拠が少なければゼロ方向に縮小。**LapFit生値は馬の過去実績に基づく相対的な適応度の代理量**。便宜的な50中心表示 `50+100×LapFit` は研究確認用スケールで、勝率・偏差値・0〜100の確定能力値ではない。

5要求量も同様に、各要求量が近いレースでの同馬の過去実績を算出する。馬が実際に各区間を何秒で走ったかはこの資料だけでは不明で、コーナー通過順位も横位置・GPSではない。

## 6. 原因分析：指数は作れたのに的中精度は上がらない

- **ラップの観測単位が違う：** JRAのレース全体ラップは基本的に先頭集団の時計。後方馬が同じ負荷で走ったとは限らない。全体ラップの近さだけでは、個体の超速力・加速持続を決定できない。
- **過去走のサンプルが疎で条件が混在：** 同一馬が「似たラップ形」で競走した回数は限られ、距離・馬場・状態・年齢・相手関係も混在。保守的な縮小で指数の振れが小さくなる。
- **市場には適性知識の一部が含まれ得る：** 確定オッズ対比の微小改善は、そのまま買える期待値ではない。
- **コース物理・真の早期位置・個馬区間時計が足りない：** ワンターン/ツーターン、最初のコーナーまでの距離、坂や直線長、実馬の前後位置は別途結合が必要。過去の上がり3F・-3F地点差を利用すれば**個体の末脚実測**には近づけるが、全200mの個体ラップは存在しない。
- **モデル入力一致が未完成：** PR #7の履歴重複除去は本番main未反映。Ability C/M3の全パイプラインおよびSafari実動作と一致するまでは研究用影響試験にとどめる。

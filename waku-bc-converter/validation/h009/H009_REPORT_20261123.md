# H009｜M3のラップ情報の重複と、同じ馬の東京・中山適性差の再現性

作成：2026-11-23。**結論：M3には過去の末脚・PCI/RPCI・位置取り・残600m差の相当量が含まれるが、全200mラップ・開催場・物理コース構造を直接入力するわけではない。競馬場適性がある馬はあり得るものの、今回の履歴平均による適性差は独立の再現性・予測上積みを確認できず、本番導入HOLD。**

## 目的・過去研究との非重複
- H007：過去10走の「競馬場±400m好走残差」の追加係数0。H008-D/E：全ラップ条件付けと馬自身の終盤反応を使った追加モデルで安定改善なし。
- H009の新たな問いは、(a) **本番M3が実際に何を入力するか**と、研究用指数との独立情報の大きさ、(b) 同一馬・同一芝距離で東京対中山の差が**前と後の走りで繰り返されるか**、(c) 過去の競馬場差が**後年の市場較正基準を追加で改善するか**。

## 1. 本番M3の静的コード監査
2026-11-23 GitHub main の `waku-bc-converter/finish600-simulator-v2.js` blob `1f1178e3003b6162243ea7286a2d859325ff9d9a`、`data/finish600_model_v1.json` を再読込。
- M3 19特徴：`pred_gap`, 過去gap中央値, PCI/RPCI中央値、上がり3Fの中央値・平均・SD、過去先行度、PCI−RPCIの中央値・平均・SD、同芝ダPCI−RPCI、同芝ダ上がり、履歴件数、出走頭数、馬番率、距離、芝ダ。
- M3順位は `score=pred_gap - predictLinear(core_m3, features)`（小さい順）。初位置の予測先頭差は別のRemaining600モデル経由。
- **開催場、コーナー物理距離、直線長、坂勾配、過去各200mのラップベクトルはM3の19特徴量に直接存在しない**。間接的に過去PCI等へ反映される余地はある。
- 現行ブラウザが取得する `hist()` は `.slice(0,5)` の5**行**。同一レースの重複除去が本番と一致するN001パリティは未確認。したがって本番M3の実出力の完全再現と称さない。
- 研究用H005 M3スコアとH008-E各馬指数を同一馬番・同一553レース8,454頭で突合し、レース内中心化Pearson相関：通常の終盤反応 `r=-0.540997`、ラップ条件付き追加反応 `r=-0.041632`。後者の馬別SDは `0.006122`、前者は `0.104956`。**通常の末脚情報はM3と重なるが、相関の大小は予測上積みの証明ではない**。H008-Eの2024年調整で条件付き追加係数0、2025〜26年好走捕捉753→747は既存研究の既知結果。

## 2. 東京 vs 中山、同馬・同芝距離の直接対照
入力は提供済みTARGET `2026_2025_seiseki.csv`（2016〜25）、`2026seiseki.csv`（〜2026-10-04）、CP932。平地3勝クラス/OP/L/G1–G3、芝1600/1800/2000、東京/中山、12〜18頭。馬番とレース日/場/R、正常結果/人気/確定単勝オッズを確認。重複と不完全カード除外。
- 該当フィルタ7,885馬行、厳格な**全頭カード479レース・7,261頭**。44レースは全頭／着順等の監査で保留。
- **東京・中山を同距離で各2走以上**経験した**183組（馬×距離）**：芝1600m105組、芝1800m47組、芝2000m31組。
- その馬について過去1回目の東京−中山差と、各場最後の東京−中山差を比較。人気から着順の上振れを `(人気順位−確定着順)/(頭数−1)` で規格化。Pearson**+0.00085**（馬×距離ペア5,000回bootstrap95%区間 **−0.146〜+0.150**）、非ゼロ175組中の同方向一致**48.6%**。着順パーセンタイルの差だけで比べても `r=+0.049`、人気パーセンタイルの差 `r=+0.213`。
- 東京−中山「人気比成績差」の馬別絶対値中央値は0.1747、一見かなり違う。しかし**同馬内で場ラベルをランダム交換**した差の絶対値平均の参考分布は**0.21225**、実測**0.21178**、片側置換p約**0.514**。見かけの差の大きさだけでは、偶然を越える馬個体固有適性が分からない。
- 診断は完全な対応時系列事前予想ではなく、両場の早い記録・遅い記録を比べた**記述的な繰返し再現性**。位置取り、ペース、対戦相手、クラス、道悪、季節を完全には制御できていない。最終オッズが既知の上振れを一部織り込む可能性がある。

## 3. 「次走でも使えるか」時系列の別検証
2016年以降の**対象クラス内の過去レースだけ**をレース日より前に使い、同距離・東京と中山の両場の人気比成績を最新12走から比較。情報の少ない個体には `(小さい方の場出走数)/(その数+3)` の縮小を適用。一般の近走好不調を別入力に保持。

2019〜23年**220レース/3,342頭**で予測係数固定。2024〜2026年10月4日**131レース/1,994頭**に評価。
- 最終単勝オッズから計算するPL3着内代理確率をH002の固定縮小率0.82264626で較正。市場基準→近走全体→東京/中山適性の順に、**2024以降を見ず**2019〜23年で単一係数決定。
- 発走前の同距離両場歴あり対象は、テスト1,994頭中324頭（2走ずつ以上は64頭）。93レースに両場歴あり馬が1頭以上存在する。
- 2024〜26年レース平均Brier：**最終オッズPL .133277069、近走好不調込み .133277054、＋競馬場差 .133277054**。上位3頭の実3着内捕捉はすべて**167頭**。2019〜23年で正の効果を要求して学習した競馬場係数は **0（数値上3.7×10⁻⁶）**。
- 感度分析として係数の正負を自由にすると、2019〜23年では **−1.794**が選ばれ（「以前良かった場を逆に減点する」方向）、2024〜26年ではBrier **.133359688**に悪化。年をまたいで有利な方向は安定せず、この係数も本番不採用。
- **最終オッズはレース後の確定価格**であり、発走15分前の実売買価格ではない。2024〜26年は既に別研究で繰り返し見た期間で、真の独立未知年でもない。対象は東京・中山の3距離・高クラスに限定、Ability C・M3本番の完全再現とは別。

## 4. 馬自身の末脚・位置移動に限った独立な補助監査
`umadete.csv` の重複除去・日付と16桁ID一致後に、**全クラスの過去走**から芝1600/1800/2000mの東京/中山を各2走以上経験した**369組**（1600:169、1800:104、2000:96）。このCSVは2026年現役登録馬を中心とする履歴なので**出走馬の選別バイアスあり**。対象はレース結果ファイルの183組と**母集団が異なるため統合・合算しない**。
- 同馬1回目と最後の東京−中山差が再現する相関：着順パーセンタイル**0.056**、人気期待比**−0.002**、自身の上がり3F−同レース最速3F**0.032**、4角→ゴールの正規化順位変化**0.068**。いずれも馬単位bootstrap95%区間に0を含む。
- 個別区間200m時計・進路・馬群ロスは観測できない。特定の馬の坂耐性や持続加速力を直接計った値ではない。

## 5. 原因候補、採否と次の検証
- JRA公式コース解説：東京芝の直線**525.9m**・高低差**2.7m**。中山芝の直線**310m**、高低差**5.3m**、ゴール前の最大勾配**2.24%**。同距離でも機械的要求条件が違うのは確実。出典： https://www.jra.go.jp/facilities/race/tokyo/course/ と https://www.jra.go.jp/facilities/race/nakayama/course/
- しかし「馬ごとの競馬場平均好走率」で強さと適性を識別することは、今回の限定された再現性検証ではできなかった。特に最終単勝市場を超える適性の独立価値は未確認。**『適性が存在しない』とは言わない**。
- 次研究候補H010：同じ距離を基本とし、公式の初角距離・坂位置・直線長・コーナー数と、その馬のas-of初位置分布・過去の段階的な位置上げ・終盤ペース耐性の**事前指定した少数の相互作用**を評価。主効果のAbility・M3と切り分け、固有馬情報が不足する場では「不明」にする。N001本番入力パリティ前の研究値を本番スコアに足さない。

**H009は診断研究のみ／公式Ability C・M3・BUY/PASS・馬券は無変更。**

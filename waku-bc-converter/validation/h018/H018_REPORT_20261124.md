# H018｜4角4位置帯の全頭同時確率と、1〜N位が重複しない隊列

**実施：2026-11-24。研究専用。本番Ability C / M3 / M4 / P10 / 買い目ロジック無変更。**

## この研究で新たに調べたこと

先行研究H017は各馬について「4角前25%、前中25〜50%、後中50〜75%、最後方25%」の確率を独立に推定した。競馬では全馬が同じ順位を取り合うため、各馬の予測を足したときに**各位置帯の許容頭数**と一致しない。H018はH017で発走前履歴から既に算出した馬別の4帯確率をそのまま受け取り、各レースの出走頭数だけで位置配分を同時調整して、H017と同一レースで比較した。**2024年以降の着順・4角実測・当日ラップ・確定オッズは、補正の入力に一切用いない**。

対応する過去研究：H013（学習側2016〜23年のコース×実4角帯の好走率）、H015（先行する確率×粘りの2段階モデル）、H017（2022〜23年で学習した4帯確率と馬の末脚・先行粘り）。同じ競馬場の得意不得意だけを加点するH009、全ラップ類似加点H008-D/E、コース構造静的補正H010とは異なる研究。

## 対象と入力・漏洩対策

- H017が検証した**2024〜2026年10月4日の977レース・14,876頭**を、そのまま1頭も増減させず使用した。全国86コース条件で、実在の4角がない**新潟芝1000m直線**は除外済み。
- 学習済みH017の `p_zone1〜4_resilience` は当該レースより前の過去走のみから生成。今回、その係数の再学習は一切行わなかった。
- コースごとの帯別3着内率を使う下流の**参考感度分析**だけ、H013が2016〜23年に固定した成功頭数・馬数を参照した（全国帯別率を30頭分の擬似標本として縮小）。この表に評価年度の確定結果は入らない。
- 実4角帯 `zone`・実3着内 `top3`・確定市場代理 `q` は精度測定専用。テスト当日ラベル・市場情報を変更しても投影結果が完全一致することを確認。

## 手法：全頭同時の位置帯・順位を整合

1. 出走頭数Nから、4角1〜N番手のうち各4帯の許容頭数を**機械的**に計算。16頭なら各4頭、17頭なら前から4・4・4・5頭。
2. H017の各馬4帯確率行列 \(P_{ik}\) を、**各馬の4帯確率の合計が1**、かつ**各4帯に入る全馬の期待人数が許容頭数**となる条件で、Kullback–Leibler距離が小さくなるよう反復比例調整（IPF / matrix scaling）する。これがH018の \(Q_{ik}\)。追加の学習パラメータなし。
3. 各帯内の順位を等確率に分割するとN×Nの**行・列和とも1**の順位確率行列になる（仮想的な1〜N順位の分布に整合）。ハンガリー法で一つの全馬同時最尤風割当を得る。**順位は重複しない**が、帯内の1番手差まで実際に区別できる推定器ではない。
4. 帯別予測値の多クラスBrier・log loss・後方半分のAUC・帯別の正解率・芝ダート別・年度別をH017と同じ実測帯ラベルで比較。Top3への参考感度は2016〜23年のコース×帯別好走率を用いて、元のH017の3着内確率に帯移動分を乗せ、1レースの3着内確率予測合計3を維持する。**これはH017の馬固有の条件付きモデルを厳密に再現したものではなく、固定補正の効果を知るためだけの試算。**

## 最大の監査結果：一意な仮想順位とTARGET実測順位は同一ではない

- 個別予測時には977R中**398R**で、少なくとも1つの4角帯の期待人数が「1〜N番手をユニークに使う」許容頭数から**1頭分超**ずれ、うち**15R**では2頭分超ずれた。1帯あたりの平均絶対ずれは**0.525頭**。最大**2.523頭**。
- H018投影後は、帯別許容人数の不一致**0/977R**、仮の1〜N順位重複**0/977R**。
- **極めて重要：実測TARGETの4角通過順位の集計は827/977Rで4帯人数が1〜Nの単純な順位定員と一致しなかった。** 公表通過順位の同順位・隊列の併走等の記録方法があり得るため、**「4角全馬に必ず厳密な順位が1つずつつく」という前提自体は観測ラベルと違う。** 整合化された仮想順位と実測4角順位を厳密な同じ量として扱ってはいけない。
- 記録帯人数が一致する**150R/2,229頭**に限定した精度も別表で集計。ここでもH018の4帯BrierはH017より小さいが、独立検証・有意差確定ではない。

## 「届かない危険馬」H013の既存598頭にはどう効くか

H013で発走前に警戒と判定していた598頭（61頭が実際の3着内）に対して、以前のH017の参考規則「最後方25%になる確率50%以上かつ研究3着内確率10%以下」では**137頭／好走7頭**、確定市場代理の期待好走数**9.48頭**だった。

同じ閾値を一切変更せず、H018の同時4帯確率＋固定補正3着内確率で判定すると、**203頭／好走10頭（4.93%）**、最終オッズ由来の市場期待**13.52頭**。増えた新規68頭は実際の3着内**4頭**で市場期待**約4.14頭**とほぼ一致し、追加的な割安/危険馬の識別証拠は出ない。市場代理3着内確率15%以上の馬も**6頭**含み、そのうち**2頭**が実際に3着以内。

したがって、**危険馬がより少数へ綺麗に絞れたわけでもなく、馬券の期待値が改善したわけでもない。** 本番自動除外は危険。

## 現段階の意味・今後の技術課題

- **達成**：H017の個別位置帯確率を変更せず、予想時点で全頭が同じ順位・位置帯枠を争うことを表現できた。全977Rで検算成功。全86条件・馬別14,876行のCSV、実着順を初期非表示のオフラインSafari向けビューア、検証テストあり。
- **未達成**：その仮想的な1〜N番手が本当の4角通過順を再現する確証。TARGET実測の同順位/ゾーン人数不整合問題、内外・スタートから3角→4角の隊列推移、馬同士のブロック・進路・ラストの各馬速度は未モデル化。
- **本番前提**：N001過去5異レースの馬名×RID重複修正、ブラウザP10/M4/3〜4角/M3/Ability Cとの完全入力パリティ。H017の研究代理予測を、本番の既存M4出力と混同しない。
- **不採用**：本番モデルへの無検証補正、特定馬の無条件消し、オッズに対するROI/期待値改善主張。確定単勝オッズは事後の市場比較にしか使っていない。

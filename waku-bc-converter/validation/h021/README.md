# H021 — ワイド1点・危険馬除外の実配当照合（研究専用）

実際の2025〜26年、621レース・9,464頭について、H018/H020の発走前特徴由来の研究予測にTARGET保存ワイドオッズ・HR2確定払戻を結合した比較です。

**重要：保存オッズの時刻は不明です。** この資料の回収率は「実際に購入可能だった馬券」の検証ではなく、配当と保存オッズの一致を利用した**事後の研究シミュレーション**です。評価年度はH001〜H020で何度も探索されており、独立テストではありません。

- `H021_REPORT_20261124.md`：研究報告。結論は「危険フラグは上位相手1点選択を変えず、9〜30倍でも変えず」。
- `H021_ワイド1点_研究戦略別比較_匿名.csv`：各戦略を1レース最大1点に限定した比較（名前なし）。
- `H021_RESULTS.json`：自動監査・全戦略・補助的候補群の数値。
- `h021_one_point_wide.py`：TARGET CP932全頭結果・馬番別保存ワイドオッズ・JV-Data HR2払戻とH018/H020予測の再計算。
- `test_h021_one_point_wide.py`：11件の研究不変条件テスト。
- `H021_TICKET_DETAIL_PRIVATE.csv`：研究戦略別の仮想買い目と払戻。馬名を含むので**GitHubへ公開しない**。
- `H021_TOP_AXIS_PAIR_POOL_PRIVATE.csv`：相手候補全集計。**1レース1点を守らない比較**なので、本戦略と混同しない。

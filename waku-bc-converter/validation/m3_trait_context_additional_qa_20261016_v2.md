# M3 末脚特性 × 今回条件：追加5CSV QA 2026-10-16 v2

## 結論

追加5ファイルを、TARGET互換変換 → 現行M3 → RPCI browser model v2 → 末脚特性スナップショット相当、の順で再生した。

今回のうち、現在の研究レイヤーの検証母集団 `JRA平地・12頭以上・M3 1〜6位` に入り、かつtrait cutoff 2026-10-04後なのは **御陵SとアイルランドTの2レース**。

- 御陵S：M3 1〜6位にTrait Aなし。
- アイルランドT：M3 4位ジョスランがTrait A。1800m + 好位〜中団想定に該当し、実2着。

したがって今回の追加有効2レースでは、研究gate `M3 1〜6 × A` は1頭中1頭が3着内。ただしn=1なので推論材料にはしない。

一方、11頭立てのサウジアラビアRC・昇仙峡Sでは、研究レイヤーの元検証範囲外なのに旧JSは表示可能だった。これはアウトカムと無関係な実装スコープ不整合なので、**12頭未満では研究レイヤーを出さない**ガードを追加した。

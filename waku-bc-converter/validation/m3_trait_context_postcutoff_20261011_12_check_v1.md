# M3 末脚特性 × 今回条件：2026-10-11/12 post-cutoff 点検 v1

Created: 2026-10-16

## Purpose

ユーザーが freeze 後に持ち込んだ4つの TARGET 全馬一括CSVを、現行V3の主要ロジックに近い形で再生し、`末脚特性A × 今回条件` 研究表示がどう出るかを点検した。

対象：

- 2026-10-11 太秦S（京都ダ1800、14頭）
- 2026-10-11 テレビ静岡賞（東京ダ1400、16頭）
- 2026-10-12 オクトーバーS（東京芝2000、18頭）
- 2026-10-12 MBSスワンS（京都芝1400、18頭）

Trait snapshot cutoff は 2026-10-04。この4レースは cutoff 後。

## QA notes

- TARGET互換レイヤーと同じく、CSVの馬の初出順を今回馬番として扱った。4ファイルとも実際の出走馬番順と一致した。
- M3は committed `finish600_model_v1` / Remaining600 formula を再生。
- RPCIは現行ブラウザが実際に使用する `rpci_browser_model_v2` を再生。
- 末脚特性は committed definition（trainer k=100, horse k=12, min history=3, A>=+0.09/B/C）による同定義ローカル再構成。ブラウザの圧縮済み名前hashスナップショットとのbyte-for-byte同一性までは保証しない。
- この4レースだけを見て条件を変更しない。点検結果は新しいholdout観察として記録する。

## Runtime-model mismatch discovered

重要なQA項目として、過去の context interaction report は RPCI browser model v1 を再現していた一方、現在のV3は `rpci-firstturn-runtime-v2.js` がv1 model fetchをv2へ差し替えるため、live contextは RPCI v2 を使用することを確認した。

4レースでは v1/v2 の top band はすべて一致したため今回のチップ発火は変わらない：

| Race | v1 top | v2 top |
|---|---|---|
| 太秦S | 45-49 | 45-49 |
| スワンS | 45-49 | 45-49 |
| オクトーバーS | 50-54 | 50-54 |
| テレビ静岡賞 | 45-49 | 45-49 |

ただし、過去の `RPCI45-49: A差 +13.1pt` はv1 replay由来なので、v2にその数字をそのまま帰属させることはできない。このためUIから過去数値を外し、v2で前向き確認中と明記する修正を入れた。

## Aggregate check

4レース12頭の実3着内に対し、base M3 top3 の重なりは 4/12 = **33.3%**。小標本ながら既存M3の約30%水準から大きく外れてはいない。

同定義Trait replayでは全出走馬のTrait Aは22頭、うち3着内5頭 = **22.7%**。B/Cは約35頭中6頭 = **17.1%**で、全体ではAが+5.6pt方向。ただしnが小さく、確認的推論には使わない。

一方、実装中の研究gate `M3 1-6 × Trait A` では11頭中3着内1頭 = **9.1%**。この4レースでは良くない。

特に、Trait Aで実際に3着内へ来た馬がM3 gateのすぐ外〜外側に複数いた：

- 太秦 #4: M3 7位 → 3着
- スワン #1: M3 9位 → 1着
- オクトーバー #16: M3 12位 → 2着
- テレビ静岡 #15: M3 8位 → 1着

これは `M3 1-6` gate が「救済」用途には狭い可能性を示す観察だが、4レースだけで7位/8位/9位/12位へ拡張すると完全な後付け最適化になる。**現時点ではgateを変更しない。**

## Decision after QA

1. 研究表示そのものは維持する。
2. M3順位・Top3確率・馬券判定への加点は引き続き禁止。
3. 固定3条件も変更しない。
4. M3 1-6 gateも、この4レースを理由に変更しない。
5. UIに出していた retrospective +13.1/+11.4/+11.1pt は削除する。RPCI条件はlive v2であるため、v1回顧数値をlive v2の根拠のように見せない。
6. 今後の新規レースで `M3 rank`, Trait, RPCI v2 top, predicted position, distance, top3 outcome を継続記録する。

## Verdict

**実装の動作条件は4CSVで想定どおり再現したが、予測面はまだ昇格不可。むしろ最初の4レースでは `M3 1-6 × A` が弱く、gate外Aの好走が目立った。これは仕様を即変更する理由ではなく、過学習防止のために現行ruleを凍結したまま追加holdoutを集めるべきというQA結果。**

## 結論
**実際のアプリが計算する過去走特徴量と、研究Pythonの特徴量を一致させたうえで、3角・4角の4群確率研究モデルをJavaScriptへ移植できた。** 2023年のみで学習し、2024・2025・2026年の既探索年度で検証。前方・好位・中団・後方の群を決め打ちする精度は依然44～46%程度であり、公式初位置/M3/Ability/P10/買い目への変更・採用は**行わない**。

## 入力仕様を一致させるまでの障害
- 前回P3-69研究は過去5異レースで計算。現行mainの`ValidatedQueueState`は、アップロードされたTARGET履歴の直近5**行**（同一レースが重複する可能性あり）で計算。2024年5,830頭の過去初位置平均が以前の研究特徴量と一致する割合は**約2.45%**。
- Draft PR #7（重複除去済み`target-csv-cache-p363-history-dedup-shadow`）相当の処理を再現すると一致率は**約95.04%**。残余不一致の主要因は、旧研究が過去に障害・中止・取消のレースを含めていた一方、PR #7の互換パーサーでは除外すること。
- 今回、障害と競走中止・取消・除外等を除き、馬名＋16桁レースIDで重複除去、**対象レースより前の日付だけ**で、最新5異レースを計算し直して新しい学習データを作成。
- 保存済みの実レース19件をPR #7相当のアプリJavaScriptで再実行。うち研究データと**全出走馬が照合できた14レース・204頭**は、過去先行度、標準偏差、ハナ率、3/4角の過去平均・変化・観測数、履歴件数という9特徴量がPython値と数値誤差（最大約1.7e−16）の範囲で一致。これら14Rでは確定馬番も全頭一致。残り5レースは今回の学習コホートと完全照合されないため**比較対象外**（「アプリ故障」とは断定しない）。
- **現行mainでは未検証の変換版／確定馬番の取り違えがあり得る。** 研究モデル`assess`は重複除去版パーサーかつ外部で確定馬番の照合済みフラグが真の場合だけ計算する。フラグだけで自動検証されたことにはならず、呼び出し側での確定馬番の根拠が必要。

## 学習モデル
- 対象：JRA平地3勝以上、12～18頭、今走の3角/4角通過位置が全頭確認できたレース。2023年3角216R/3,258頭、4角218R/3,296頭。2023年時系列65/35に分けて正則化強度を選択して再学習。
- **発走前に得られる18数値特徴量のみ**：出走頭数、距離、芝ダ、実馬番の枠位置、過去走件数、前へ行く傾向、そのSD、過去ハナ率、過去3角平均、過去4角平均、過去3→4角移動平均、有効3角/4角走数、本人より前へ行きやすい馬数、その内側人数、全頭平均との差、先行馬数、近い馬番の先行馬数。
- 4群の区切りは前方25%・好位25～50%・中団50～80%・後方20%。16頭なら固定4・4・5・3席。同順位は境界の席を按分した**ソフト正解**として多項ロジスティック回帰を学習。
- **今走の通過順位・結果・最終人気・オッズは説明変数に入れない**。今走の通過順位は学習/評価ラベルとしてのみ使用。

## Python / JavaScriptの再現性
- JavaScript `waku-bc-converter/corner-group-shadow-v1.js` と、集約係数JSON `data/corner_group_research_model_v1.json` を**別研究ブランチ**に追加。モデルは`RSACornerGroupShadowV1.assess(queue,meta,model,options)`で完全出走馬・過去3走以上・重複除去版・確定馬番照合を要求。

## 本番切替を保留する理由と次
1. **PR #7の履歴データ正規化は未マージ**で、現行mainにこの分類器を接続すると元の入力定義と一致しない。
2. 取消等で仮番号≠確定馬番になるケースがある。既存`ShapeCore`の仮番号と公式出走馬番の全頭照合が済むまでコーナー群モデルの発火禁止。
3. 3角/4角の確率は独立に推定しており、**同一の仮想レースの3角→4角進出軌跡の確率**はまだ学習していない。
4. 未使用の今後のレースで発走前に予測JSONを固定し、年度別Brier4、logloss、前方群捕捉、グループ正解率、順位整合性と見送り条件を監査する。

**M3・Ability・P10・公式の隊列仮想抽選・軸・買い目・BUY/PASSは無変更。今回の実装は研究用の独立コードと係数のみで、本番`v3.html`には読み込ませない。**

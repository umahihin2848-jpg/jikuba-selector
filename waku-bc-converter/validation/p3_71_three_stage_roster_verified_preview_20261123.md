# P3-71：確定馬番を全頭照合した「初位置→3角→4角」研究プレビュー（2026-11-23）

## 結論
**研究版アプリで、3地点を同じ出走馬と照合して表示する独立プレビューを作成し、実Chromium上で操作を通した。** ただし「初位置」は過去先行度の順を示す**参考配置**、3角/4角は2023年学習のP3-70モデルによる**互いに独立した4群予測**。正確なコーナー上の前後順・レーン・GPS進路・3角→4角の移動経路を予測したものではない。

**本番main、Ability C、ValidatedQueue、Remaining600、M3、P10、買い目・BUY/PASSの計算は変更しない。** GitHub Draft PR #8上のみの実験。PR #8は未マージDraft PR #7（TARGET重複除去）をベースとするため、そのまま本番へマージしない。

## 画面・仕組み
- 研究ブランチの`v3.html`に以下のみを追加（本番サイトに追加したわけではない）。
  - `corner-stage-roster-audit-v1.js`：`馬番,馬名`の全出走馬リストと、現在の`ValidatedQueueState.rows`の**馬名を1対1で照合**。同馬名/同馬番、未入力馬、未知名、本人の確認欄未チェック、出典ラベル不足を検知して停止。欠番はそのまま保持し、仮馬番→出走表の馬番へ研究モデル内だけで割り当て直す。出走表の出典はユーザーが入力し確認する方式で、**JRA等の公式APIから自動確認したものではない**。
  - `corner-stage-three-preview-v1.js`／CSS：展開隊列タブの研究折りたたみ。出走表入力→照合→初位置（過去先行度による参考順）／3角／4角の3段階切替。4群は前方25%・好位25～50%・中団50～80%・後方20%、16頭なら4/4/5/3席。3角/4角は未較正の群所属確率を表示し、代表群への予測確率が50%未満なら「入替注意」。
  - `corner-group-shadow-v1.js`と`data/corner_group_research_model_v1.json`：P3-70の2023年学習済み18特徴量モデル（変更なし）。**CSVの版は重複除去済み`target-csv-cache-p363-history-dedup-shadow`、各馬過去3異レース以上、12～18頭、手動出走表の全頭一致を必須**とする。
- 研究用JSONに入力レース条件・出走表の出典・欠番・仮番号→確定馬番の対応・初位置の過去先行度参考グループ・3角/4角の群所属確率と代表群、席数と計算版を保存。ユーザー端末上で任意操作により保存、**サーバーに自動アップロードしない**。端末生成時刻は公式な発走前タイムスタンプを証明しない。
- レース条件、CSV、出走表、研究入力が変わった場合は出走表の再確認を要求。非同期モデル読み込み中の競走馬データ差替えも再検査。
- 3角→4角で代表グループが変わる馬の数を参考表示するが、これは独立した2つの予測の比較であり、実際の追い上げ/後退の「確率」ではない。内/外/中レーンは学習も表示もしていない。

## 限界と必須の次工程
- **出走表を自動的に公的ソースへ照合してはいない。** 馬名の正規化（NFKC、空白除去）を使ったユーザー提供の出走表対CSVの一対一照合であり、本人の参照元が正しいことを保証できない。現行本番に自動的に取り込んで購入ゲートへ接続しない。
- 取消馬の欠番はID対応として扱えるが、`gate_frac=(実馬番−1)/(出走頭数−1)`は、上位馬番が実頭数より大きい場合に1を超える。**当該ケースの確率較正は未検証**で、実戦で信頼できる数値とは主張しない。将来の学習では発走前に確認済みの枠数・馬番母数・取消履歴を別に扱う必要がある。
- 実際の初位置はコースを考慮した学習済み3段階モデルではなく、過去の先行度の参考順。3角/4角は個別の4群推定であって、全頭の正確な1～n番手、レーン、隊列の物理的な追走シミュレーションではない。
- 2024～26年は以前の研究でも使用した探索年度。2027年以降の未使用レースを事前に記録して、位置帯Brier・前方候補捕捉・群一致率・欠番ケースの性能を独立検証する。
- 次：**実馬の確定馬番／枠情報を正規の出走表から安定取得する独立データパス**、入力版の監査、研究ブランチの表示UIのiPhone Safari実機検証、未使用レースでのスナップショット運用。

# 相手馬3頭の選び方｜Ability C / M3 / 事前位置取り比較（2026-11-20）

## 判定
**実装変更は見送り。現行Ability C順位優先・M3同順位補助を維持。** M3を25%加える仮説は小幅に改善したが、2026年に改善を確認できず、統計的優位性は未証明。

## 比較の条件
アップロード済み `umade.csv` と過去のAbility C再構成 `ability_c_m3_horse_roles_2024_2026.csv`、Pair v1履歴照合 `c_pair_v1_confirmation_races.csv` を利用。全重賞258Rから、一意な軸を現在の構造ルールに近い条件で固定できる112R（2024年46R／2025年39R／2026年10月4日まで27R）を抽出。2025〜26年の66RはC1単独31R、A2単独16R、Pair→v1軸19R。

**全方式は同じ軸馬を除外して相手3頭を選ぶ。** 軸・相手の選択に確定着順、当日実際の通過順、レース後オッズは使わない。順位の加重（75:25、50:50、25:75）であり学習済み確率の加重ではない。

## 2025〜26年：相手3頭が3着以内になった延べ頭数（66R）
| 方式 | 頭数 | 1頭以上好走 |
|---|---:|---:|
| **現行Ability順位優先** | **65** | **49/66 = 74.2%** |
| Ability75%＋M3 25% | 67 | 50/66 = 75.8% |
| Ability50%＋M3 50% | 65 | 50/66 = 75.8% |
| Ability25%＋M3 75% | 53 | 45/66 = 68.2% |
| M3順位のみ | 48 | 41/66 = 62.1% |
| 50:50＋過去走前方度・先行割合の簡易補正 | 57 | 48/66 = 72.7% |
| 50:50＋過去走脚質の分散 | 65 | 50/66 = 75.8% |

Ability75%＋M3 25%と現行方式の**対応レース単位の平均差**は +0.030頭／R。12,000回ブートストラップ95%区間は **-0.091〜+0.152頭／R** でゼロを含む。相手の顔ぶれが変わった33R中、現行より改善10R・悪化8R。

2024年：現行43頭 vs 75:25方式46頭（46R）。2025年：40頭 vs 42頭（39R）。2026年：25頭 vs 25頭（27R）。再現性を証明するには不十分。

## 隊列・位置取りの適用範囲
事前情報のみ：対象レースより古い最大5走の最初に記録される角の相対位置（前方度）。**2走以上の履歴がある馬にのみ使用**。2025〜26年の軸以外978頭中893頭（91.3%）に必要履歴あり。先行割合30%を閾値とした簡易補正や脚質分散を比較したが、**アプリのValidated Queue本体、コース形態、内外位置を完全に再現した検証ではない**。この結果だけで隊列モデルを否定できない。

## 限界
- Ability C再構成258Rと別の元研究262Rは一致していない。**本番Cの厳密な再現ではない**。
- 軸を一意に決められない146Rは相手候補3頭の比較対象から除外。66Rの成績を全重賞の性能とみなさない。
- 2024〜2026年は既にモデル開発・仮説探索に使用したデータ。**手付かずの外部検証ではない**。
- 複数方式を比較した探索であり、区間推定だけでは最優秀方式の有意性を証明できない。
- 旧C＋市場オッズ方式との厳密な比較は実施していない。発走前の同一時点オッズを再現できる資料が未確認のためで、現在のユーザー要件ではオッズは選定ではなく参考表示。

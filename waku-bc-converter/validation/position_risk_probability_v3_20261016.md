# Position Risk v3: 「今回10番手以下になる確率」の事前予測

作成日: 2026-10-16

## 目的

従来の Position Risk v2 は、過去最大3走の序盤位置中央値が10番手以上なら Risk とする二値ルールだった。

v3 では、発走前情報だけから

`P10 = P(今回の最初の有効通過順位が10番手以上)`

を 0〜100% の連続確率として予測できるか検証した。さらに、過去の位置取り履歴だけでなく、同一レース他馬の先行傾向（先行圧）、馬番、距離、競馬場、芝ダート、コース区分、コーナー数を加えたときに改善するかを確認した。

重要: 当該レースの通過順位は目的変数にのみ使用し、説明変数はすべて当該レースより前のJRA走歴と発走前に確定しているレース条件だけを使用した。

## データ

全JRA履歴: `umadete.csv`

M3対象レース: `m3_position_risk_recon.csv` のうち、JRA平地・3勝クラス以上・12頭立て以上。

`umadete.csv` は `(レースID(新・馬番無16桁), 血統登録番号)` で重複除去し、74,724のユニークな馬×レース出走に整理した。

今回、現行 `umadete.csv` でほぼ完全に全JRA履歴を再構築できる2024〜2026を使用した。

- 2024: 371レース / 5,626頭
- 2025: 373レース / 5,651頭
- 2026: 274レース / 4,194頭

外国馬等で現行履歴に一致しなかった3頭は除外した。

## 目的変数

通過1→2→3→4の順で最初に得られる正の通過順位を `actual_first` とし、

- `actual_first >= 10` → 1
- `actual_first < 10` → 0

とした。

実際の10番手以下率は:

- 2024: 36.90%
- 2025: 36.74%
- 2026: 37.43%

## 発走前特徴量

### 馬自身の過去位置取り

当該レースより前のJRA走歴のみを使用。

- 過去3走の序盤位置: median / mean / SD
- 過去3走の10番手以下率
- 過去3走の頭数正規化位置: median / mean
- 直近走の序盤位置 / 正規化位置 / 10番手以下フラグ
- 過去5走のfrontness平均 / SD
- 過去5走の逃げ率（1番手）
- 過去5走の3番手以内率
- 同芝ダート過去3走の正規化位置 / 10番手以下率
- 過去3走の平均頭数
- 有効履歴数

### レース全体の先行圧

各馬について、自馬を除く同一レース他馬の「過去走から作った」情報だけを集約した leave-one-out 指標。

- 他馬のfrontness平均
- 他馬の逃げ率平均
- 他馬の3番手以内率平均
- 高frontness馬の比率

したがって、当該レースの実際の隊列・通過順位は一切使っていない。

### 枠・コース構造

- 頭数
- 馬番を頭数で正規化した gate fraction
- 距離
- 芝 / ダート
- 競馬場
- コース区分 A/B/C/D 等
- コーナー数

現行の履歴CSVには厳密な「スタートから1角までの距離」の歴史値がないため、今回のコース形状は上記の代理変数である。first-turn distanceそのものの検証ではない。

## 検証プロトコル

全モデルは2024だけで学習し、2025・2026へ係数固定で適用した。

モデルは過学習を避けるため ridge logistic regression を使用。確率予測の比較を主目的とし、Brier / LogLoss / AUC を評価した。

比較:

1. `Binary v2`: 従来の10番手中央値Risk + known + 頭数
2. `History continuous`: 馬自身の連続的な位置取り履歴
3. `History + gate/course`: 2 + 馬番・距離・芝ダ・競馬場・コース区分・コーナー数
4. `History + pressure`: 2 + 他馬の先行圧
5. `Full v3`: 2 + 先行圧 + gate/course

2025/2026は今回の仮説作成以前からプロジェクト内で繰り返し確認済みの年なので、厳密には pristine OOS ではない。以下は固定年分割による retrospective holdout / sensitivity として扱う。

## 2. どの情報が効いたか: ablation

2025-26 pooled、レース単位cluster bootstrap。

### 先行圧を追加: History + pressure vs History

- ΔBrier = -0.004951
- 95%CI 約 [-0.00588, -0.00400]
- ΔLogLoss = -0.01329
- 95%CI 約 [-0.01559, -0.01100]

明確に改善。

### gate/courseを追加: History + gate/course vs History

- ΔBrier = -0.000393
- 95%CI 約 [-0.00093, +0.00016]
- ΔLogLoss = -0.00107
- 95%CI 約 [-0.00233, +0.00027]

点推定では改善するが、95%CIは0を跨ぐ。

### Full v3 vs History + pressure

- ΔBrier = -0.000125
- 95%CI 約 [-0.00046, +0.00022]
- ΔLogLoss = -0.00020
- 95%CI 約 [-0.00107, +0.00069]

したがって、今回のv3改善の中心は **同一レース他馬の事前先行圧**。馬番・距離・競馬場・コース区分・コーナー数は補助的で、今回の符号化では独立改善がまだ明確でない。

馬単位cluster bootstrapでも Full v3 vs History のBrier差95%CIは約 [-0.00644, -0.00378] で0を跨がず、同一馬の反復出走を考慮しても方向は維持した。

## 3. 確率較正

Full v3 の2025-26 pooled:

| 予測P10帯 | n | 平均予測P10 | 実際の10番手以下率 | Top3率 |
|---|---:|---:|---:|---:|
| <20% | 3,206 | 11.36% | 11.07% | 23.92% |
| 20-35% | 2,045 | 27.06% | 27.34% | 20.83% |
| 35-50% | 1,510 | 42.20% | 40.33% | 20.07% |
| 50-65% | 1,357 | 57.39% | 58.29% | 17.24% |
| >=65% | 1,727 | 76.83% | 77.13% | 12.45% |

較正回帰:

- 2025: intercept -0.023 / slope 0.989
- 2026: intercept +0.024 / slope 1.049
- pooled: intercept -0.003 / slope 1.015

理想は intercept=0 / slope=1 なので、2025・2026とも確率較正はかなり良好だった。

特に `P10 >=65%` は実測77.1%、`P10 <20%` は実測11.1% と大きく分離した。

## 4. M3へ追加した場合

P10モデルの2024学習値をそのまま2024 Top3モデルへ流すとstacking leakageになるため、2024内では race-group 5-fold OOF でP10を生成。そのOOF P10でTop3モデルを学習し、2025/2026では2024全体で学習したP10モデルを固定適用した。

Top3モデルのBaseline:

- M3 score
- M3 rank fraction
- 頭数

比較:

- Baseline
- + Binary Position Risk v2
- + continuous P10 v3

P10 v3 vs M3 baseline:

- ΔBrier = -0.001807
- race-cluster 95%CI 約 [-0.00272, -0.00091]
- ΔLogLoss = -0.00594
- 95%CI 約 [-0.00867, -0.00314]

馬単位cluster感度分析でもBrier差95%CI 約 [-0.00280, -0.00081] で0を跨がない。

したがって、**連続P10はM3だけでは拾えていない位置取りリスク情報を持つ**という結果。

ただし P10 v3 vs Binary v2 の差は:

- ΔBrier = -0.000342
- race-cluster 95%CI 約 [-0.00097, +0.00033]

で0を跨ぐ。点推定はv3が良いが、現時点で「M3補助としてv3がv2より統計的に明確に優れる」とまでは言えない。

## 5. M3上位馬での解釈

2025-26 pooledの記述統計。

### M3 1〜6位

| P10帯 | n | Top3率 |
|---|---:|---:|
| <20% | 1,153 | 31.40% |
| 20-35% | 808 | 27.85% |
| 35-50% | 594 | 25.08% |
| 50-65% | 565 | 24.42% |
| >=65% | 762 | 17.06% |

M3上位でも、P10が高いほど取りこぼしが増える方向が非常に明瞭。

M3 1〜3位だけでも:

- P10 <20%: Top3 36.92%
- P10 >=65%: Top3 21.20%

これは「能力評価が高いが後方配置リスクが高い馬」を警告する用途と整合する。

## 統計学的な解釈

今回支持されたのは、単なる「過去に10番手以下だった馬は弱い」ではない。

より正確には:

1. 過去の位置取りは、今回10番手以下になる確率をかなり予測できる。
2. その確率は0/1の固定閾値より連続量として扱う方が情報量が多い。
3. **同一レース他馬の事前先行圧を加えるとさらに明確に改善する。**
4. 枠・距離・競馬場等の現在の代理的コース形状情報は小幅改善に留まり、独立効果はまだ不明確。
5. P10はM3 Top3予測にも追加価値を持つ。
6. ただしv3がBinary v2よりM3補助として明確に優位かはまだ未確定。

## Production decision v3

現時点ではアプリ本体・M3順位・馬券判定は変更しない。

研究表示として採用候補:

`POSITION RISK / P10 72%`

例:

- `<20%`: 後方配置リスク 低
- `20-35%`: やや低
- `35-50%`: 中
- `50-65%`: 高
- `>=65%`: 強い後方配置注意

M3順位は変更せず、M3上位馬の「取りこぼし警告」として表示するのが現時点で最も妥当。

## 次の必須確認

- 2026-10-16時点で特徴量定義・モデル構造を固定する。
- 以後の新規レースでP10の較正（予測帯 vs 実測率）をprospective記録する。
- 20〜30レースでは方向確認、50〜100レース以上で較正とM3増分を再評価する。
- first-turn distanceを歴史的に正確に付与できるなら、現在のvenue/distance代理変数を置き換えてコース形状効果を再検証する。
- prospectiveで再現するまではM3順位への直接ペナルティは入れない。

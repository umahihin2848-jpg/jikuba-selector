# 事前馬場数値 → 前後Bias 検証 expansion v2

作成日: 2026-10-16

## 目的

pilotで東京・中山・京都・札幌・函館の5場に見えた「JRA朝発表のクッション値・含水率が、能力・ペース補正済みの前後Biasを事前に説明できるか」を、未検証だった阪神・中京・新潟・福島・小倉へ拡張して再現性を確認する。

今回も目的はM3順位を直接いじることではなく、朝の公開情報だけで「前有利 / 中立 / 後ろ有利」の事前Biasを作る根拠があるかの検証である。

2025/2026は本プロジェクト内で既に繰り返し参照しているため、pristine OOSではなく回顧的holdout / sensitivityとして扱う。

## データ

前後Bias側は既存の `front_back_track_bias_2024_2026_v1` と同じ `bias_adj` を使用。正なら前方馬の能力・市場・ペース補正後の上振れ、負なら後方馬の上振れ方向。

JRA馬場数値は日付・競馬場で結合した。

- 芝クッション値
- 芝ゴール前含水率
- 芝4角含水率
- ダートゴール前含水率
- ダート4角含水率
- 使用コース A/B/C/D
- 開催日目

追加5場の結合対象は阪神・中京・新潟・福島・小倉。

2025は対象212/212レースで結合。2026は公開データが揃った126/152レースを結合した。2026の未結合開催は欠損として除外し、0等で補完していない。

モデルは2025だけで正則化を選び、2026へ固定して評価した。venue-day単位のgroup CV / cluster bootstrapを用いた。

## 1. 芝：残り5場への拡張

- 2025 train n=137
- 2026 test n=80

Baseは競馬場、公式馬場状態、天候、使用コース、距離、開催日目。数値追加は競馬場内2025年平均/SDで標準化したクッション値、芝平均含水率、ゴール前-4角の含水率差を追加したRidge。

### 2026結果

- Base RMSE: 0.277701
- +馬場数値 RMSE: 0.277575
- Base MAE: 0.222895
- +馬場数値 MAE: 0.222770
- corr: 0.1888 -> 0.1910
- Bias正負 AUC: 0.5219 -> 0.5119

venue-day cluster bootstrap:

- ΔMSE = -0.000070, 95% CI [-0.001012, +0.000814]
- ΔMAE = -0.000125, 95% CI [-0.001690, +0.001372]

誤差の点推定はごく小さく改善したが、CIは広く0を跨ぎ、Bias正負AUCはむしろ低下した。

**結論: 芝はクッション値・含水率だけでは実用的な前後Bias予測にならない。**

pilot 5場と合わせても、芝の主な追加候補は数値より「現在の傷み位置」「内柵移動」「使用コース切替」などのコース状態情報である。

## 2. ダート：残り5場への拡張

- 2025 train n=75
- 2026 test n=46

平均含水率とゴール前-4角差を追加したモデルでは、

- Base RMSE: 0.273036
- +馬場数値 RMSE: 0.273493
- Base MAE: 0.221439
- +馬場数値 MAE: 0.220816
- corr: 0.0816 -> 0.0433
- Bias正負 AUC: 0.5203 -> 0.5091

venue-day cluster bootstrap:

- ΔMSE = +0.000250, 95% CI [-0.002831, +0.003481]
- ΔMAE = -0.000623, 95% CI [-0.006570, +0.004978]

多変量数値モデルとしては改善が再現しなかった。

### 単純な連続含水率だけ

複雑化を避け、競馬場内標準化した平均含水率1変数だけを追加すると、

- Base RMSE: 0.273036
- +含水率 RMSE: 0.272674
- Base MAE: 0.221439
- +含水率 MAE: 0.220945
- corr: 0.0816 -> 0.0890
- Bias正負 AUC: 0.5203 -> 0.5233

cluster bootstrap:

- ΔMSE = -0.000197, 95% CI [-0.000631, +0.000175]
- ΔMAE = -0.000495, 95% CI [-0.001339, +0.000272]

ごく弱いシグナルは残るが、CIは0を跨ぎ、production採用には不足。

2次・3次の非線形化、競馬場別含水率交互作用は2026で悪化し、小標本に対する過学習が疑われたため採用しない。

## 3. pilotで見えた「高含水 = 前有利」は再現するか

最初の東京・京都・中山では、2025年各競馬場の含水率中央値を閾値として固定したとき、2026でも高含水側が前有利方向へ出た。

しかし残り5場で同じ設計を再現すると結果は反転した。

### 2025 残り5場

- 低含水: n=34, mean bias_adj = +0.0526
- 高含水: n=41, mean bias_adj = +0.0040
- 競馬場・公式馬場状態・開催日目・距離調整後の高含水係数: +0.0150
- SE 0.0736, p=0.839
- 95% CI [-0.129, +0.159]

### 2026 残り5場

- 低含水: n=19, mean bias_adj = +0.0866
- 高含水: n=27, mean bias_adj = +0.0264
- 調整後の高含水係数: **-0.2283**
- SE 0.1047, p=0.029
- 95% CI **[-0.4335, -0.0232]**

2026の単純high-low差も、標本は小さいが中京・小倉・新潟・福島・阪神の5場すべて負方向だった。

良馬場だけに絞っても2026は -0.2504方向だが、標本が小さく95% CIは0を跨いだ。

### 重要な更新

したがってpilotで見えた

> ダートは含水率が高いほど普遍的に前有利

という解釈は撤回する。

東京・京都・中山とその他の競馬場群で方向が異なり、競馬場構造・砂質・距離構成・標本構成などとの強いheterogeneityが疑われる。

参考として、2026のpilot主要3場の高含水係数 +0.2326 と今回5場 -0.2283 を、それぞれのSEで単純fixed-effect結合すると約 +0.040、95% CI 約 [-0.092, +0.173]。heterogeneityのI²は約91%となる。これはモデル仕様・標本が完全同一ではないため診断的な参考値であり、主解析としては用いない。

**全場共通の「高含水 = 前有利」ルールは現時点では支持されない。**

## 4. 芝の「傷み」情報の扱い

JRAの馬場概要には、例えば以下のような情報がある。

- コース全周内側に先開催の傷みが残る
- 3〜4コーナー内柵沿いに傷みが残る
- 全体的にコース内側に若干の傷み
- 傷んだ箇所を張替・補修し、現在は全体的に良好

ここで単純に文章中に「傷み」が出たら1とするのは不適切。過去の傷みを補修済みで現在良好という記述も多いため、**現在状態と補修履歴を分離**する必要がある。

今後固定する候補フラグ:

- `residual_damage_current`: 現在も傷みが残る
- `inner_damage`: 内側/内柵沿いの現在傷み
- `corner34_damage`: 3〜4角の現在傷み
- `straight_damage`: 直線の現在傷み
- `uneven_turf`: 芝の不揃い
- `repair_history`: 張替・補修履歴だが現在傷みとは別
- `current_good`: 全体的/概ね良好
- `rail_shift_m`: 内柵移動量
- `course_variant`: A/B/C/D

過去検証では「開催開始時の馬場概要」は取得可能だが、開催途中の週ごとの傷みを完全に再現する履歴は別途必要。よって開催概要を使う場合は、**週次の実際の傷みのproxy**として扱う。

## 5. 統計的解釈

今回の拡張で重要なのは、5場pilotだけなら魅力的に見えたダート含水率の方向が、別の5場で反転したこと。

これは検証としては良い結果であり、5場だけでproductionルールへ進めていれば過学習/局所則を採用していた可能性が高い。

現時点では物理馬場情報は、

1. レース速度・走行条件には意味がある
2. しかし「前有利/後ろ有利」へ単純変換できるほど普遍的ではない
3. 特に競馬場別の構造差を十分な標本で扱う必要がある
4. ただし競馬場別の柔軟な交互作用を今の小標本で学習すると過学習する

という状態。

## Production decision v2

- M3順位: **変更しない**
- Top3較正: **変更しない**
- 馬券判定: **変更しない**
- 芝クッション値/含水率によるBias補正: **未採用**
- ダート含水率による普遍的な「前有利」表示: **未採用 / pilot解釈を撤回**
- 馬場情報を使った前後Bias: **研究表示もまだ保留**
- 芝の現在傷み情報: **次の検証候補**

## 次の検証

### A. 芝

JRA馬場概要の現在状態を固定ルールで分類し、クッション値・含水率・A/B/C/D・開催日目に追加する。2025で分類/係数を固定し2026で確認する。

ただしmeeting-start概要だけの場合は週次状態のproxyと明記し、結果を過大解釈しない。

### B. prospectively

今後の開催はレース前に、JRAの当日/週次馬場情報を保存する。

保存項目:
- timestamp
- raw condition text
- parsed damage flags
- cushion value
- turf/dirt moisture
- A/B/C/D
- rail position
- meeting day
- weather/going

結果確定前に保存しておけば、未来情報漏れなしで将来の前後Biasとの関係を検証できる。

## 現時点の結論

朝の公開馬場数値だけで前後Biasを高精度に断定するモデルはまだ作れない。

特にダート含水率は、最初の5場だけの結果を全場へ一般化できなかった。

一方、芝は数値よりも「現在どこが傷んでいるか」「内柵をどれだけ動かしたか」が未検証の主要候補として残る。次はここを固定カテゴリ化して検証する。

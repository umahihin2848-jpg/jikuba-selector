# 事前馬場数値 → 前後Bias 検証 pilot v1

作成日: 2026-10-16

## 目的

JRAが開催当日朝に公表するクッション値・含水率だけで、当日の途中レース結果を使わずに「前有利 / 後ろ有利」の事前情報を作れるかを検証する。

## データ

前後Bias側は既存の `front_back_track_bias_2024_2026_v1` と同じ思想で、能力・市場・ペースをできるだけ差し引いたレース単位の `bias_adj` を使用。正なら前方馬の上振れ、負なら後方馬の上振れを示す。

JRA数値側は開催日朝の以下を結合した。

- 芝クッション値
- 芝ゴール前含水率
- 芝4角含水率
- ダートゴール前含水率
- ダート4角含水率
- 使用コース A/B/C/D

今回のpilotで結合済みの競馬場は東京・中山・京都・札幌・函館。2025年を学習/development、2026年を時系列holdoutとして扱った。ただし2025/2026は本プロジェクト内で既に繰り返し参照しているため pristine OOS ではなく回顧的holdout / sensitivity である。

## 1. レース単位の連続Bias予測

ベースラインは事前に分かる競馬場・馬場状態・天候・使用コース・開催日目・距離。数値追加モデルは競馬場内で2025年平均/SDに標準化した含水率（芝はクッション値も）を追加したRidge。正則化強度は2025年のvenue-day group CVのみで選択し、2026年へ固定した。

### 芝

2025 train n=183、2026 test n=114。

- Base RMSE: 0.290333
- +数値 RMSE: 0.290049
- Base MAE: 0.233893
- +数値 MAE: 0.233654
- Base corr: 0.1929
- +数値 corr: 0.2178
- Bias正負 AUC: 0.5965 -> 0.5908

cluster bootstrap（venue-day）:

- ΔMSE = -0.000165, 95% CI [-0.000786, +0.000410]
- ΔMAE = -0.000238, 95% CI [-0.001212, +0.000693]

改善は極小でCIは0を跨ぐ。クッション値・芝含水率だけでは前後Biasを実用精度で読む証拠は得られなかった。

### ダート

2025 train n=110、2026 test n=68。

- Base RMSE: 0.286479
- +含水率 RMSE: 0.283533
- Base MAE: 0.209741
- +含水率 MAE: 0.208650
- Base corr: 0.0733
- +含水率 corr: 0.1244
- Bias正負 AUC: 0.5944 -> 0.6163

cluster bootstrap（venue-day）:

- ΔMSE = -0.001680, 95% CI [-0.003956, +0.000490]
- ΔMAE = -0.001091, 95% CI [-0.004758, +0.002567]

点推定は改善したが、CIは0を跨ぐため production 採用には不足。

## 2. ダート含水率の方向性

東京・京都・中山に絞り、2025年の各競馬場内中央値を固定閾値として「高含水 / 低含水」に二分し、2026年にも同じ閾値を適用した。

2025:
- 低含水 mean bias_adj = -0.0776（n=54）
- 高含水 mean bias_adj = +0.0390（n=56）
- 無調整差 ≈ +0.1165

2026:
- 低含水 mean bias_adj = -0.0977（n=37）
- 高含水 mean bias_adj = +0.0111（n=31）
- 無調整差 ≈ +0.1089

競馬場・公式馬場状態・開催日目・距離を調整したOLS（venue-day cluster robust）でも、高含水の係数は

- 2025: +0.1864, 95% CI [+0.0412, +0.3316], p=0.0119
- 2026: +0.2326, 95% CI [+0.0590, +0.4063], p=0.0087

で同方向だった。

ただし含水率と良/稍重/重/不良は強く相関するため、残余交絡の可能性はある。良馬場だけに絞った感度分析でも同方向だったが標本は小さい。

- 2025 良のみ: 高含水係数 +0.1620, 95% CI [-0.0339, +0.3579]
- 2026 良のみ: +0.2181, 95% CI [+0.0577, +0.3785]

現時点では「ダートは含水率が高い日に前方有利方向へ寄りやすい可能性」が最も有望な仮説。

## 3. 馬単位Top3への直接追加

前走までの位置取り傾向 `hist_front3` と含水率の交互作用を、東京・京都・中山のダートで馬単位Top3モデルへ追加した。

2025で学習し2026へ固定。Baseは単勝オッズ、頭数、距離、過去位置取り、クラス、競馬場、馬場状態など。

2026:

- Base Brier 0.133759 / LogLoss 0.417115 / AUC 0.790958
- 高含水×位置取り追加 Brier 0.133988 / LogLoss 0.417898 / AUC 0.790467
- 連続含水率×位置取り追加 Brier 0.133865 / LogLoss 0.417630 / AUC 0.790809

直接のTop3予測改善は再現しなかった。市場オッズを抜いたモデルでも改善なし。

したがって、現時点で含水率をM3順位・Top3確率へ加点する根拠はない。

## 解釈

1. 芝: クッション値・含水率だけでは弱い。芝は傷み位置・内柵移動・使用コース・開催進行の情報を追加する必要性が高い。
2. ダート: 含水率には再現する方向性が見える。特に低含水日は前方有利が弱く、高含水日は前方有利方向へ寄る傾向が2025/2026で同方向。
3. ただし馬単位Top3への直接追加は未改善。現段階ではスコア補正ではなく研究表示候補に留める。

## Production decision

- M3順位: 変更しない
- Top3較正: 変更しない
- 馬券判定: 変更しない
- 芝事前Bias: 未採用
- ダート含水率: **研究表示候補（未採用）**

次の検証は、全10場へ拡張したうえで、芝についてJRA馬場概要の「内側の傷み」「3〜4角の傷み」「直線の傷み」「芝張替/補修」「A/B/C/Dコース替わり」を固定カテゴリ化し、2025でルール固定→2026で確認する。

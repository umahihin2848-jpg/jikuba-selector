# 事前馬場数値 → 前後Bias 検証 pilot v2

作成日: 2026-10-16

## 目的

JRAが開催当日朝に公表するクッション値・含水率を使い、当日の途中レース結果を見ずに「前有利 / 後ろ有利」の事前情報を作れるかを検証する。

v1の5場（東京・中山・京都・札幌・函館）に阪神を追加し、場依存の見かけの効果が残るかを確認した。

## データ / 設計

前後Bias側は既存 `front_back_track_bias_2024_2026_v1` と同じ `bias_adj`。正なら能力・市場・ペース等を考慮しても前方馬が上振れ、負なら後方馬が上振れした方向。

朝の馬場数値:
- 芝クッション値
- 芝ゴール前 / 4角含水率
- ダートゴール前 / 4角含水率
- 芝A/B/C/Dコース

2025をdevelopment、2026を固定holdoutとして使用。正則化強度や標準化は2025側だけで決めた。ただし2025/2026は本プロジェクトで既に参照済みなので pristine OOS ではなく回顧的holdout / sensitivity と扱う。

対象6場: 東京・中山・京都・阪神・札幌・函館。

2026評価レース数:
- 芝 142レース / venue-day 101 cluster
- ダート 87レース / venue-day 78 cluster

## 1. 芝: クッション値 + 含水率

Baseline: 競馬場、公式馬場状態、天候、A/B/C/D、開催日目、距離。

追加モデル: 競馬場内で2025年平均/SDに固定標準化した芝含水率平均とクッション値を追加。

2026:
- Base RMSE 0.294641
- +数値 RMSE 0.294546
- Base MAE 0.237742
- +数値 MAE 0.237731
- 相関 0.0685 -> 0.1029
- Bias正負AUC 0.5187 -> 0.5067

venue-day cluster bootstrap:
- ΔMSE = -0.0000563, 95% CI [-0.001092, +0.000880]
- ΔMAE = -0.0000116, 95% CI [-0.001555, +0.001553]

結論: 数値を足した改善は実質ゼロ。クッション値・芝含水率単独では前後Biasのproduction採用根拠にならない。

競馬場別の数値傾きを許すRidgeはRMSE 0.293294まで改善したが、2025の限られたサンプルで場別自由度を増やすため探索的。ここをproduction採用するには別年/将来データでの再確認が必要。

## 2. ダート: 含水率

Baseline: 競馬場、公式馬場状態、天候、開催日目、距離。

追加モデル: 競馬場内で2025年平均/SDに固定標準化したダート含水率平均。

2026:
- Base RMSE 0.279648
- +含水率 RMSE 0.279680（わずかに悪化）
- Base MAE 0.211479
- +含水率 MAE 0.208485（わずかに改善）
- 相関 0.1058 -> 0.1332
- Bias正負AUC 0.6076 -> 0.6500

venue-day cluster bootstrap:
- ΔMSE = +0.0000183, 95% CI [-0.003377, +0.003248]
- ΔMAE = -0.002994, 95% CI [-0.010156, +0.003900]

結論: 方向分類AUCやMAEには改善方向があるが、誤差CIは広く0を跨ぐ。production補正には不足。

## 3. 「高含水なら前有利」仮説の頑健性

v1では東京・京都・中山で、2025各場中央値を閾値にした高含水ダミーが2025/2026とも前方有利方向に見えた。

今回は阪神を追加し、東京・京都・中山・阪神で再確認。

2025各場中央値（%）:
- 東京 4.725
- 京都 5.70
- 中山 5.35
- 阪神 4.75

無調整平均 bias_adj:

2025:
- 低含水 n=68: -0.0320
- 高含水 n=70: +0.0145

2026:
- 低含水 n=41: -0.0800
- 高含水 n=42: +0.0107

見た目の方向は同じだが、競馬場・公式馬場状態・開催日目・距離を調整したvenue-day cluster robust OLSでは:

- 2025 高含水係数 +0.1236, 95% CI [+0.0032,+0.2440], p=0.044
- 2026 高含水係数 +0.0382, 95% CI [-0.1213,+0.1977], p=0.639

阪神を追加すると2026の効果は大幅に弱まり、有意ではなくなった。

競馬場別にも方向が一定ではない。したがって「含水率が高ければ一律に前有利」とする固定ルールは採用しない。

## 4. 馬単位Top3への追加

東京・京都・中山・阪神のダートで、2025を学習し2026へ固定。

Baseline:
- log単勝オッズ
- 頭数
- 距離
- 過去3走位置取り傾向
- 履歴数
- 開催日目
- 競馬場 / クラス / 馬場状態 / 天候

比較:
- 高含水フラグ + 高含水×過去位置
- 連続含水率z + 含水率z×過去位置

2026（1,255 runners / 87 races）:

Baseline:
- Brier 0.133268
- LogLoss 0.417318
- AUC 0.790297

高含水フラグ:
- Brier 0.133425（悪化）
- LogLoss 0.417633（悪化）
- AUC 0.789840（悪化）

連続含水率:
- Brier 0.132990（小改善）
- LogLoss 0.416831（小改善）
- AUC 0.790993（小改善）

venue-day cluster bootstrapで連続含水率のBrier差は
- ΔBrier = -0.000278
- 95% CI [-0.000647,+0.000051]

LogLoss差も95% CIが0を跨いだ。

したがって馬単位のTop3予測にも、まだ頑健な上積みとは言えない。

## 統計学的な読み方

v1の3場ではダート高含水にかなり良い見え方があったが、阪神を足しただけで2026の調整済み効果が弱まった。これは、少数場で閾値を作ってproduction実装すると場固有効果を一般化してしまう危険性を示している。

一方、ダートの連続含水率はAUC・MAE・馬単位Brierで小さな改善方向が残ったため、完全に捨てる必要もない。現段階の位置づけは「有望な研究変数」であり「加点変数」ではない。

芝についてはクッション値・含水率だけで前後Biasを読む力は弱い。芝は数値よりも、内側/3-4角/直線の傷み、芝張替・補修、A/B/C/Dへのコース替わり、開催進行との交互作用を検証する価値が高い。

## Production decision

現時点では変更しない:
- M3順位
- Top3較正
- Ability
- 馬券判定

表示についても、`前有利` / `後ろ有利` と断定するproduction badgeはまだ出さない。

次の固定検証:
1. 残り4場も追加して10場化
2. 芝馬場概要文を事前定義した固定フラグに変換
3. `傷み位置 × A/B/C/D × 開催日目 × クッション値/含水率` を2025 developmentで固定
4. 2026 historical holdoutで再確認
5. その後の将来開催でprospective確認

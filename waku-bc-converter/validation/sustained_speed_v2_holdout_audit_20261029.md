# 持続力 v2 実データ再構築・ホールドアウト監査 2026-10-29

## 結論

現行の持続力 v1（`min(道中速度z, 上がり速度z)`）をそのまま予測に使うのは継続して見送る。

一方、**「後5Fで速い流れが長く続いたレースを経験し、その負荷の中で位置を保ち、最後3Fでも失速せず、ゴールまで差を保てたか」**を直接寄せた持続力 v2 は、v1 より明らかに研究価値が高い。

ただし、2024〜2026 の確認では 2026 年に逆転が残ったため、**まだ予測確率・総合順位・馬券判断には入れない。**

判定:

- `SUSTAINED_SPEED_V2 = RESEARCH_SHADOW`
- `PREDICTION_IMPACT = NO`
- `PROBABILITY_IMPACT = NO`
- `TICKET_IMPACT = NO`
- `REPLACE_V1_IN_UI = NOT_YET`
- `KEEP_2027_AS_FORWARD_CONFIRMATION = YES`

---

## なぜ v2 を作り直したか

v1 は、各過去走について

- 道中速度
- 上がり速度

の弱い方を持続力としていた。

これは「全体的に速く走れた馬」を拾う一方で、競馬でいう持続力、すなわち

- 残り1000m付近から動く
- 4〜5F長く脚を使う
- 一度上げた速度を長く保つ

を直接測っていなかった。

長期監査では持続力要求が高いレースで持続力上位馬の成績が安定せず、2023〜2026ではむしろ逆方向だったため、定義そのものを再構築した。

---

## データ上の制約

TARGET/JRA系データには、各馬の個別4F・5Fタイムそのものはない。

利用できるのは主に、

- レース後5Fラップ
- 各馬の上がり3F
- 上3F地点差
- 通過位置
- 着差 / 着順

である。

したがって v2 は「各馬の5Fタイムを観測した」とは扱わない。

**レース全体で4〜5F持続負荷が発生したかを先に測り、その負荷の中で各馬がどこまで位置・末脚・差を保てたかを持続力の証拠とする。**

---

## 検証分離

2024〜2026を見ながら式を調整すると確認年が汚れるため、以下の順序を固定した。

1. 2016〜2023の履歴から基準分布を作る
2. 実用上のデータ充足率が高い2023を開発確認年として使う
3. 定義を固定
4. 2024 → 2025 → 2026を順に開ける
5. 2024〜2026を見た後は式を変更しない

2019〜2022は全クラス履歴の充足率が低いため、中心判断には使わない。

## レース側｜持続要求 v2

後5Fを F5 → F1 とする。

### 1. 5F全体速度

`speed5 = 3600 / (F5 + F4 + F3 + F2 + F1)`

同じ芝/ダート×距離を基本に2016〜2023基準で百分位化する。

サンプルが少ない距離は、芝/ダート×距離帯、それでも不足する場合は芝/ダート全体へフォールバックする。

### 2. 速いラップの連続長

F5〜F1の各位置について、2016〜2023の同条件中央値より速いラップを `fast=1` とする。

その5区間の中で最長の連続 `fast` 数を求める。

例:

`1,1,1,1,0 -> 4F持続`

`0,1,1,1,1 -> 4F持続`

`1,0,1,1,0 -> 最長2F`

### 3. 速度維持

`maintenance = -std(F5,F4,F3,F2,F1)`

ばらつきが小さいほど、一度上げた速度を維持したラップとして高評価にする。

### 4. レース持続要求スコア

- 5F全体速度 percentile
- 連続長 percentile
- 速度維持 percentile

の単純平均を取り、さらに2016〜2023の重賞対象レース内で百分位化する。

上位25%を `持続要求が高い` とする。

重みの最適化は行っていない。

## 馬側｜持続力 v2

1走ごとの「持続負荷への対応」を以下で作る。

### A. 3F地点まで位置を保てたか

`gap_score = 1 / (1 + max(上3F地点差, 0))`

前との差が小さいほど高い。

### B. 最後3Fでレースラップに対して脚を残せたか

`last3_relative = レース後3F - 馬自身の上がり3F`

プラスほど、レース全体の後3Fより速い上がりを使ったことを示す。

これを2016〜2023の芝/ダート×距離基準で百分位化する。

### C. 3F地点からゴールまで差を保てたか

`gain3 = 上3F地点差 - ゴール着差`

プラスほど、残り3F地点からゴールまで前との差を詰めた / 保ったことを示す。

これも2016〜2023基準で百分位化する。

### D. 1走の持続証拠

`response = mean(gap_score, last3_relative_pct, gain3_pct)`

`evidence = race_sustained_demand_pct × response`

### E. 馬の持続力 v2

対象レースより前の直近最大5走を使用し、3走以上の有効履歴がある場合に

`Sustained v2 = mean(last 5 evidence)`

とする。

未来レースは一切使わない。

## 開発確認｜2023

持続力 v2 上位3頭について、実際に持続要求が高かったレースとその他を比較。

- 持続要求高: 32.4%
- その他: 28.8%
- 差: **+3.6pt**

単勝オッズを同時に考慮した交互作用:

- OR 1.038
- 95%CI 0.510–2.112
- p = 0.918

生の方向はプラスだが、2023単年では追加効果を統計的に確定できない。

なお複数候補を確認したが、単純に過去着順を強く使う方式は一般能力との混同が大きいため採用せず、上3F地点差・自身上がり・3F地点からの差の変化を使う上記定義を主候補として固定した。

## ホールドアウト｜2024 → 2025 → 2026

### 持続力 v2 Top3 の3着内率

| 年 | 持続要求高 | その他 | 差 |
|---|---:|---:|---:|
| 2024 | 36.8% | 25.5% | **+11.3pt** |
| 2025 | 31.3% | 28.8% | **+2.5pt** |
| 2026 | 23.3% | 28.8% | **-5.5pt** |

方向は **2年プラス / 1年マイナス**。

### 2024〜2026 pooled

- 持続要求高: 30.3%
- その他: 27.6%
- 差: **+2.8pt**

レース単位 bootstrap 95%CI:

- **-2.8pt 〜 +8.3pt**
- bootstrapで差がプラスとなった割合: **83.4%**

0をまたいでいるため、まだ確定とはしない。

### 単勝オッズ調整後

2024〜2026で、単勝オッズ・持続力v2 Top3・持続要求高・両者の交互作用を入れ、レース単位cluster robust SEで確認。

- 一致効果 OR: **1.249**
- 95%CI: **0.843–1.852**
- p = **0.268**

方向はプラスだが、統計的には未確定。

## v1 との関係

現行 v1 の長期監査では、持続要求との一致効果は近年不安定で、2023〜2026合計でも逆方向だった。

v2 は、少なくとも

- 2024で大きく正方向
- 2025で小幅正方向
- 2024〜2026 pooled で正方向

まで改善した。

ただし v1 と v2 では「レース持続要求」の定義自体も変更しているため、数値の直接比較は参考扱いとする。

重要なのは、**2026でまだ逆方向が残ったこと**である。

## 2026の診断

式は変更せず、原因確認だけ行った。

2026の一致差は概ね:

- 芝: 約 -6.7pt
- ダート: 約 +5.6pt

距離帯では1900〜2200m付近のマイナスが大きかった。

これは次の研究仮説にはなるが、2026を見た後に芝補正・距離補正を追加することはしない。

後付け最適化を避けるため、現 v2 の式はここで固定する。

## 統計的な判断

### 良くなった点

- 「道中と上がりの弱い方」から脱却した
- 実際の後5Fラップを直接使う
- 速い速度の連続長を入れた
- 位置を保ったかを入れた
- 自身の最後3Fの反応を入れた
- 2024・2025は正方向
- pooledも正方向

### まだ不足する点

- 2026が逆方向
- pooled 95%CIが0をまたぐ
- 単勝オッズ調整後の追加効果が未確定
- 各馬個別の4F・5Fタイムを直接観測しているわけではない

したがって、**v2は有望な研究指標だが、完成した能力指標ではない。**

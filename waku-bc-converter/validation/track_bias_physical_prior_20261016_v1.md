# 前後TRACK BIAS：事前物理情報モデル検証 v1

作成日: 2026-10-16

## 目的

当日の途中レース結果を使わず、朝の時点で取得できる馬場情報から「前有利 / 後ろ有利」の事前Biasを推定できるかを検証する。

候補情報は以下。

- 芝クッション値
- 芝含水率（ゴール前 / 4コーナー）
- ダート含水率（ゴール前 / 4コーナー）
- 馬場状態
- 芝使用コース A/B/C/D
- 開催何日目
- 天候
- JRA馬場概要の芝傷み記述（内側、3-4角、直線、全体等）

最終目的はM3を直接書き換えることではなく、まず表示専用の前後TRACK BIAS priorを作り、前向き検証できる状態にすること。

## 既存データでの先行検証（代理変数）

クッション値・含水率をまだ結合していない段階で、TARGET内に既にある事前情報だけを使った代理検証を実施した。

対象は `frontbias_complete_races.pkl` の2023-2026、計1,654レース。目的変数は、既存の前後Bias検証で作成した能力・ペース補正後の race-level `bias_adj`。

### 基本モデル

- 芝/ダート
- 競馬場
- 距離

### 物理代理モデル

基本モデルに加えて

- 馬場状態（良 / 稍 / 重 / 不）
- 芝使用コース A/B/C/D
- 天候
- 開催何日目

を追加。

2023を学習、2024を正則化強度選択に利用し、その後2023-24で再学習。2025・2026で固定評価した。

## 結果

### 2025

- 0予測 RMSE: 0.29691
- 基本モデル RMSE: 0.29799
- 物理代理モデル RMSE: 0.29667

物理代理モデルは基本モデルより約0.00131改善したが、0予測との差はごく小さい。

### 2026

- 0予測 RMSE: 0.28370
- 基本モデル RMSE: 0.28329
- 物理代理モデル RMSE: 0.28276

物理代理モデルは基本モデルより約0.00053改善。

### 2025-26 pooled

- 基本モデル RMSE: 0.29192
- 物理代理モデル RMSE: 0.29093
- MSE差（物理代理 − 基本）: -0.000580
- venue-day cluster bootstrap 95% CI: **[-0.001865, +0.000708]**

0を跨ぐため、現段階で統計的に明確な改善とは言えない。

## 単純カテゴリは年を跨いで安定しない

例として補正済みBiasの平均は、

- 芝Cコース: 2025 +0.036、2026 +0.119
- 芝Aコース: 2025 -0.016、2026 -0.003

となったが、競馬場・距離・開催構成が混ざっているため「Cコースだから前有利」とは解釈しない。

馬場状態についても年ごとの差が大きく、良/稍重/重/不良だけでは高精度の事前Biasは作れない。

## 重要な進展：公式データ取得経路を確認

JRA公式には過去の含水率・クッション値アーカイブがあり、含水率は2018年7月27日以降、クッション値は2020年9月11日以降が公表されている。開催回ごとのPDFには開催日単位で、

- 使用コース
- クッション値
- 芝含水率（ゴール前 / 4コーナー）
- ダート含水率（ゴール前 / 4コーナー）

が入っている。

また、JRA公式PDFを構造化CSVへ変換した公開実装・公開データの存在も確認した。2025/2026データは日付・競馬場・開催回・使用コース・クッション値・芝/ダート含水率を列として保持している。

このため、次段階の本検証は実行可能。

## 芝傷み情報の扱い

JRA馬場概要の文章は数値ではないため、最初から恣意的な点数化はしない。以下の固定フラグへ変換する。

- damage_none_or_good
- damage_slight
- damage_inside
- damage_corner34
- damage_straight
- damage_widespread
- repair_or_reseed
- aeration
- watering

「内側に傷み = 差し有利」のようなルールを先に決めず、係数はデータ側に推定させる。

## 次の本検証プロトコル

### 1. 日次JRA物理データを結合

レース結果へ `date × venue` で以下を結合。

- cushion_value
- turf moisture goal / 4C
- dirt moisture goal / 4C
- turf_course_variant
- meeting day
- going
- damage flags

芝とダートは別モデルとする。

### 2. 目的変数

既存検証と同じく、単純な逃げ残り率ではなく、能力・頭数・距離・競馬場・クラス・ペースを差し引いた「前方馬の上振れ量」をBias観測値とする。

### 3. データ分割

閾値調整を同じ年で繰り返さない。

- development: 過去年
- model selection: 次年
- confirmation: 最終年

2025/2026は本プロジェクトで既に多数参照しているため、最終的な新ルールの pristine OOS としては扱わず、retrospective holdout / sensitivity と明記する。

### 4. 比較

最低限、

A. 競馬場・芝ダート・距離だけ
B. + 馬場状態 / 使用コース / 開催日
C. + クッション値 / 含水率
D. + 芝傷みフラグ

を段階的に比較する。

評価指標:

- race Bias RMSE / MAE / correlation
- 前有利 / 中立 / 後ろ有利の識別
- M3 top3残差との交互作用
- venue-day cluster bootstrap CI

### 5. Production判定

現時点では **表示・M3補正とも未実装**。

実装条件は、数値馬場情報を加えたモデルが年を跨いで再現し、かつBias適合/逆風でM3残差またはTop3に実用的な差が確認できた場合のみ。

## 現時点の結論

TARGETに既にある「馬場状態・A/B/C/D・開催何日目」だけでは、前後Biasの説明力はごく小さく不確実。

一方、JRA公式のクッション値・含水率は日次で取得可能で、芝傷み・仮柵情報も別途構造化できるため、**朝の事前情報だけで前後Bias priorを作る仮説はまだ十分検証価値がある**。
